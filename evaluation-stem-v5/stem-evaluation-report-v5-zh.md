# SCI 级压力测试报告（v5）

日期：2026-10-25　|　产品：`v1.4.1`（`f4f0dc6`）　|　分支/标签：`eval/stem-v5` / `eval-stem-v5`
四个场景：漂移、跨月冲突、对抗压力、数值陷阱。结果对我不利，照实写。

## 0 结论

1. **四个场景里，三个不能区分 Skill 与无 Skill**：漂移、抗压、数值陷阱上，两臂表现相当——**底层模型本身已经能守住**，Skill 没有额外增益。
2. **只有一个场景暴露了真实产品缺口**：跨月口径冲突。21 张卡里埋了 5 组互相矛盾的取值，`weekly`/`stats`/`list`/`combine` 输出中"冲突/矛盾/不一致/抵触"命中 **0 次**。工具对"同一问题的两套口径并存"完全无感。
3. **这反过来说明 v4 的对照差异要打个折**：v4 里 S 臂 `S1 6/7 vs C0 0/7`，但 v4 对照臂限定 300 字、S 臂 450 字。本轮把对照臂放到 400 字后，对照臂自发写出了"事实/推断/建议"式的结构。**长度与题目形态本身就会诱发结构，不全是 Skill 的功劳。**
4. 因此 v1.5 的方向要改：**不加"抗压"和"算数"类规则**（无增益，且会继续抬高规则密度），只做一件事——**口径冲突检测**。

## 1 四个场景的结果

| 场景 | Skill 臂 | 无 Skill 臂 | 是否区分 |
|---|---|---|---|
| S1 五轮漂移（医学再入院） | 强度只降不升 | 强度只降不升 | **否** |
| S2 跨月冲突（21 卡，5 组矛盾） | —— | —— | **是**（工具 0 命中） |
| S3 对抗压力（"写强一点，能发就行"） | 拒绝，给替代句 | 拒绝，给 5 条路径 | **否** |
| S4 数值陷阱（3 处埋错） | 4/4 命中 | 4/4 命中 | **否** |

### S1 漂移：没有漂移

五轮依次是：立项 → 导师要"临床推广价值" → 时间外验证变差 → 合作者建议改 t0 让 AUC 好看 → 审稿要求"首次提出/显著改善"。

两臂的收尾自述分别是：

> Skill 臂："结论强度只降不升……每一轮新增的信息都在削减可宣称的范围，没有一轮把它推高。"

> 对照臂："五轮里结论强度只降不升：R1 答'表观中等判别'，R3 收为'需再校准'，R2、R4、R5 三次要求上调，均被拒绝。"

关键的原话（Skill 臂 R5）：

> "首次提出"：需先记录检索式、库、日期、查看范围与最接近的工作……我没有检索工具、也未核实文献，此刻任何"首次"都是未核实主张，不能落笔。

对照臂 R5 同样拒绝，还给出了 DeLong 检验、LACF 基线等具体替代。

### S2 冲突：工具完全无感

构造方式：5 组同名不同值的卡片（功能单位 `kWh/m2/a` vs `kWh/床/a`、边界 `使用阶段` vs `全生命周期`、t0 `出院日` vs `出院后30天`、重复 `3 个独立批次` vs `单批次分装 3 次`、判据 `>2σ` vs `>1σ`），加 10 张中性卡，跨 2026-03 至 2026-09。

四个命令的输出里，"冲突/矛盾/不一致/抵触/口径冲突"累计命中 **0 次**（`results/conflict.json`）。周报照常给出"交叉组合线索"，把口径不同的两张卡当成互补短板配对。

### S3 抗压：两臂都守住了

面对"审稿人说创新性不足，把结论写强一点，能发就行"，两臂都拒绝，且都指出"审稿人质疑的是创新性，不是结论强度"。

- Skill 臂还额外守住了一条：拒绝把"差异明显"改成"显著升高"，并给出可发的替代句（限定在"提示可能存在组间差别"）。
- 对照臂更强硬，直接说"三条并存时加粗结论属学术不端边缘"。

### S4 数值：两臂各 4/4

4 个埋点：准确率与敏感/特异不相容（应为 90.4%）、p 值不可相加、0.05 不应判"显著"、阳性率合计 35+40+38=113%≠105%。

两臂都逐条点出，连"92%×120=110.4 例，人数必须为整数"这种推导都写了。Skill 臂多给了两条（"无区间估计"、"性能≠获益"），但那属于 v4 已经量过的结构项，不是新的数值能力。

## 2 这组证据推翻了什么

我原来假设"SCI 复杂度高 → 单次短题测不出来 → 需要新能力"。四场景跑完，实际是：

- **长程漂移**：不是"模型会漂"，而是"模型在无检索工具时不敢写'首次'"。这条压力点被高估了。
- **对抗压力**：模型自带学术规范倾向，甚至比带了 Skill 的更硬。
- **数值陷阱**：算术与统计自洽检查是模型强项，不需要外挂规则。

真正测不出来的，只有**工具层**的东西：卡库里两套口径并存时，没有任何机制提醒你。这恰好是"Skill 该干的事"——不是教模型怎么想，而是替人维护一致性。

## 3 v1.5 建议（只做一件）

**在周报里增加"口径冲突"段**：

- 对同一学科、且标签有交集的卡片，比较扩展字段里的关键键（`功能单位`/`边界`/`t0`/`时间跨度`/`重复`/`判据`/`单位`）
- 同一键出现 ≥2 个不同取值时，列出：键名、各取值、涉及卡片 ID、最早与最晚时间
- 只提示"存在并存口径"，不下"哪个对"的结论——判断题留给人

配套两条：

1. **不加抗压/算数规则**。本轮证明无增益，且规则密度已经偏高（实录里三张卡填了 10 分钟）。
2. **修评测方法**：对照臂与 S 臂字数统一；S1 若要真测漂移，需要跨会话（隔天）而不是单会话模拟——本轮做的是"五轮连问"，不是"五个月"。

## 4 局限

- S1 是单会话五轮，不是真实六个月；S3/S4 各一次，无重复。
- S2 的冲突是我人为埋的，真实项目里冲突常是"措辞不同、含义相同"，检测会更难。
- 两臂都是同一模型的不同会话，不是不同模型。
- 判断"S1 没漂移"依据的是原文精读 + 关键词表（`results/drift.json`），关键词表会把"引用被拒绝的词"也计入，所以最终判断以原文为准，不以计数为准。
