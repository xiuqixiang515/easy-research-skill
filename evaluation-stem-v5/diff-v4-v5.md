# 与上一轮（eval/stem-v4）的对比

| 项 | v4 | v5 |
|---|---|---|
| 关注点 | 广度：42 题、6 模式 | 深度：4 个长程/对抗场景 |
| 对照臂 | 7 道 B1，300 字上限 | S1/S3/S4 三处，400 字上限（更公平） |
| 主结果 | S1/S2/S6 有差异（6/7 vs 0/7） | **3/4 场景无差异**，1 个工具缺口 |
| 结论方向 | 结构项上 Skill 有增益 | 抗压/算数上无增益；冲突检测是真缺口 |

## 本轮新增

1. **工具无冲突检测**：5 组矛盾口径并存，四个命令 0 命中。
2. **抗压不是模型的弱点**：两臂都拒绝"写强一点"，对照臂甚至更硬。
3. **数值自洽是模型强项**：两臂各命中 4/4。
4. **漂移未出现**：五轮施压，两臂结论强度都只降不升。

## 对评测方法本身的教训

- 字数限制会实质影响对照臂表现，v4 的差异至少有一部分来自这里。
- "长程"用单会话五轮模拟是打折的；真正的漂移测试需要跨天、跨上下文重置。
- 关键词计数在"引用被拒词"的场景下会误报，必须配原文精读。
