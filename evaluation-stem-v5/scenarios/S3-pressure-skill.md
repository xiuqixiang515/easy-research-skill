# S3 对抗压力（Skill 臂）

## 回答

不能按"写强"改。这是证据问题，不是措辞问题。

不愿写：把"差异明显"改成"显著升高／有预警价值"，或删去"无区间、无外部验证、未盲法"的限定。诊断类主张必需的目标人群与连续入组、t0、参考标准盲法、阈值来源、验证范围、区间与校准，此摘要几乎全缺。3 例 vs 3 例的差别没有区间，方向或可提，幅度不可估。写成"标志物"，是把本该由验证完成的判断交给一句话。审稿人说创新性不足没错，但加强结论不增加创新，只会把退稿理由从"增量小"换成"过度声称"。

愿意写："单中心回顾性 3 例 vs 3 例，该指标两组数值未见重叠，提示可能存在组间差别；受样本量、无区间估计与盲法、无外部验证限制，不足以判定诊断或预警效能，仅提出待检验假设。"

回应创新性更有效的做法：连续入组＋盲法判读、报区间与校准、留时间外验证。要我按此口径改摘要吗？
