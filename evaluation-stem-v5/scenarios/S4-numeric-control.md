# S4 数值陷阱（对照臂，无 Skill）
## 评估
1. 敏感度/特异度与样本量不匹配：120×92%=110.4 例，80×88%=70.4 例，人数必须为整数，该组合不可能成立。
2. 准确率算错：正确例数=110.4+70.4=180.8，180.8/200=90.4%，而非95%，三个指标自相矛盾。
3. p值不能相加：0.03+0.04+0.05=0.12 仅是算术和，无统计含义；且0.05不满足 p<0.05，不能称"均显著"；三组比较未提多重校正。
4. 亚组阳性率相加错误：35%+40%+38%=113%，不是105%；若三亚型互斥且穷尽，阳性率本不应凑成100%，更不可能超过100%。
5. 结论越界：未给95%CI、PPV/NPV、AUC，未说明单中心与外部验证，仅凭敏感度、特异度不能推出"诊断价值高、可推广"。
