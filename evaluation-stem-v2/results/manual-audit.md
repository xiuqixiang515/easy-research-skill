# 人工抽查（8 份，约占受评文本 21%）

抽查对象：`text-grades.json` 的 38 段受评文本（17 份对照 + 21 段稳定性）中抽 8 份。
抽查方式：人工按 `rubric.md` 的定义逐项判断，与正则输出逐项比对，只记录**不一致**的项。

| 样本 | 正则判定（未命中项） | 人工判断（应未命中项） | 不一致 |
|---|---|---|---|
| `C0-computer.md` | S1,S2,S5,S7 | S1,S2,S5,S7 | 无 |
| `C0-energy.md` | S1,S2,S5,S6,S7,S8 | S1,S2,S5,S7 | **2 项**：S6、S8 |
| `C0-medicine.md` | S1,S2,S5 | S1,S2,S5 | 无 |
| `C1-chemistry.md` | S2,S5,S7 | S2,S5,S7 | 无 |
| `S-computer.md` | S7 | 无（数据/对照/判据齐备，仅缺字面"指标"） | **1 项**：S7 |
| `S-energy.md` | S6,S7 | S7 | **1 项**：S6 |
| `S-mechanical.md` | S7 | 无 | **1 项**：S7 |
| `stability/medicine.md` 第 2 次 | — | — | 无（S1–S8 与人工一致） |

## 不一致的三种成因

1. **S8 误报（C0-energy）**：文本里的"辅助能耗…占比更高"是能耗占比，不是"贡献占比"。正则把任何"占比"都算作违规，产生假阳性。→ S8 在本轮对 C0 的扣分中至少有 1 例不成立。
2. **S6 漏报（C0-energy、S-energy）**：两段都写了"就不能下方向性结论""无法解释"，但没有出现"无法判断/信息不足/不确定"这些字面词，正则判为未通过。人工认为不确定性已表达。→ S6 存在漏报。
3. **S7 系统性漏报（S 臂 6/7）**：S 臂的"建议"段落普遍给出"基准 + 种子 + 判据"这类最小验证要素，但没有逐字出现"数据/对照/指标/判据"四个词中的三个。正则几乎只认 `判据`。→ **S7 在本轮不可作为定量指标，降级为定性**。

## 对结论的影响

- 8 份抽样中 3 份存在不一致，共 5 个条目级分歧（S8×1、S6×2、S7×3 计次）。
- 按条目计，S7 的误判率最高（抽样中 3/3 应为通过），因此报告中 **S1、S2、S3、S5、S8 保留定量计数，S6 标注"可能偏低 2 例"，S7 只作定性讨论**。
- S8 的假阳性意味着 C0 臂的 S8 计数（6/7）实际可达 7/7，即 S 臂与 C0 在 S8 上**没有差别**——这一条不能作为 Skill 的增益证据。
