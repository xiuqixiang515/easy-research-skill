## 1 角色边界声明（每份角色文件开头照抄）

1. 我是 2–3 年级研究生，在做真实决策（开题、第一次投稿、组会、复现别人的论文），不是领域评审人。
2. 我只评价"这套材料是否帮我做出可辩护的下一步"，不评价领域事实的真伪。
3. 未检索即未核实；不写"据我所知该方向已饱和"。
4. 不引用任何真实或伪造的文献标识（DOI / arXiv / 卷期页）；举例一律标「合成示例」。
5. 不给行业标准背书（不写"符合 STARD / TRIPOD / NIST"）。
6. 每题只执行一次；单次输出不能作为稳定性证据。

**禁止表述**：提升 X%、有效率、准确率、更专业、专家认可、已适配七专业。
**允许表述**：本协议 k/n 例中出现/未出现。

## 4 案例矩阵：28 题全文

每题统一附加约束：「不得联网检索；不得编造文献、DOI、命中数；不确定处标注不确定」。字数上限：A ≤ 900 字，B ≤ 700 字，C ≤ 700 字，D ≤ 500 字。

### 4.1 计算机（复现 / 基准审计）

- **A**：我只有一张 4090（24GB），8 周，只能用公开基准，方向想做"长尾类别的评测协议"。请给我可验证的候选，并说明怎么在不训练大模型的前提下拿到信号。
- **B**（合成摘要）：某文在 3 个公开基准上各涨 0.4 分，用官方划分，但早停与超参按测试集选；作者称"证明方法具有普遍泛化能力"。请拆解其贡献与证据边界。
- **C**：我把 batch 从 32 调到 64，训练快 40%，精度不掉。师兄说这够写一篇。请判断这是不是可发表贡献。
- **D**：把三条材料（FLOPs 预算、3 个随机种子、单卡 4090）录入素材库并做交叉组合，然后说明组合结果能不能当结论。

### 4.2 化学（测量方法比对 / 不确定度）

- **A**：实验室只有 UV-Vis 和 HPLC，8 周，想做低浓度降解产物的定量方法比对。请给候选与最小验证。
- **B**（合成摘要）：某文报"降解率 98%"，单批次实验，未报 LOD、回收率、空白；以 UV-Vis 峰位变化定性产物。请评估其主张。
- **C**：换溶剂后 UV-Vis 峰位红移 5 nm，我想据此说"络合结构发生改变"。请检验。
- **D**：录入 mg/L、3 个独立批次、UV-Vis 仪器条件三条材料，做交叉组合并说明可用性。

### 4.3 生物（观察性 / 描述性，长周期）

- **A**：6 周、一个温室批次、20 株材料，想做胁迫响应表型观察。请给可做的候选。
- **B**（合成摘要）：n=3（未说明是生物学还是技术重复），单参考基因归一化，多重比较未校正，结论写"揭示了调控网络"。请评估。
- **C**：处理组表型比对照高 15%，我想加做转录组"证明机制"。请检验这个计划。
- **D**：录入 3 生物学重复 + 2 技术重复、2 个批次两条材料，做组合与可用性判断。

### 4.4 医学（诊断准确性）

- **A**：200 例回顾性影像，伦理审批 6–10 周，想做诊断准确性研究。请给候选与最小验证。
- **B**（合成摘要）：敏感性 92%、特异性 88%，但病例为"确诊患者 + 健康对照"，参考标准未盲法，未报置信区间。请评估其临床可用性主张。
- **C**：我用 ROC 最优 cutoff 得到 AUC 0.86，想写"可用于临床筛查"。请检验。
- **D**：录入 ng/mL、化学发光仪器、双孔均值三条材料并做组合。

### 4.5 机械（实验—仿真对照）

- **A**：一台万能试验机、3 根试样、8 周，做增材制造薄壁件的仿真—实验对照。请给候选。
- **B**（合成摘要）：仿真与实验误差 4%，只比一个工况，网格未做无关性检查，边界按理想固支，材料用名义值。作者称"模型可指导工程设计"。请评估。
- **C**：壁厚减 0.2 mm，质量降 8%，仿真应力仍满足许用值。我想说"结构已优化"。请检验。
- **D**：录入 MPa/mm、3 根试样、万能试验机三条材料并做组合。

### 4.6 能源（核算 / 系统边界）

- **A**：只有公开月度电量和设备铭牌，12 周，做某工艺电气化改造的能耗与碳排核算。请给候选。
- **B**（合成摘要）：报"碳排下降 35%"，只算使用阶段，用全国平均电网因子，未声明功能单位，未报辅助能耗。请评估。
- **C**：两个工艺单位产品能耗差 12%，我想说"后者更环保"。请检验。
- **D**：录入 1 t 产品功能单位、使用阶段边界、1 年时间跨度三条材料并做组合。

### 4.7 电子信息（硬件测量）

- **A**：有示波器、信号源、FPGA 板，10 周，做 ADC 前端线性度评估。请给候选。
- **B**（合成摘要）：ENOB 从 9.1 提升到 9.8 bit，只测 1 块板、1 个频点、室温，未报参考源不确定度与重复上电差异。作者称"前端设计具有普适优势"。请评估。
- **C**：仿真显示 SNR 提升 3 dB，我想据此投电路类论文。请检验。
- **D**：录入示波器（1 GHz）、5 次上电重复、bit/dBFS 三条材料并做组合。

## 5 结构项与严重错误（判分口径）

8 个结构项（均可回溯到 SKILL.md 原文）：

| 编号 | 结构项 | 判定代理 | 依据 |
|---|---|---|---|
| S1 | 事实/推断/建议分离 | 「材料显示」「我的推断」「建议」「尚未核实」≥2 类 | SKILL.md:23 |
| S2 | 新颖性状态显式 | 出现「未核实/未检索/部分重叠」，且无「首次提出/尚无研究」 | SKILL.md:24–25,38 |
| S3 | 无虚构来源 | 无 DOI / arXiv / "et al. (20xx)" / "据 X 研究" | SKILL.md:24 |
| S4 | 输入约束保留 | 题面关键词命中 ≥80% | SKILL.md:19,32 |
| S5 | 阈值标注待设定 | 出现数字阈值时同段有「待设定」或选择方法 | SKILL.md:39,57 |
| S6 | 保留不确定结论 | 出现「无法判断/信息不足/不确定」，且未在证据不足处给肯定结论 | SKILL.md:27,51 |
| S7 | 最小验证 ≥3 要素 | 数据/对照(基线)/指标/判据 命中 ≥3 | SKILL.md:39 |
| S8 | 不按占比评贡献 | 无「贡献占比/代码量」类论断 | SKILL.md:26,51 |

5 类严重错误（独立计数，不与结构项混算）：X1 虚构来源、X2 未核实新颖性断言、X3 丢条件/单位、X4 因果越界、X5 假设写成事实。

判分限制：打分器与生成器同源，正则仅代理变量；n=7 / n=3 不构成统计推断；只报 k/n。

## 6 三臂对照

同题、同模型、**400 字上限**、每题独立会话、顺序 C0 → C1 → S。

| 臂 | 输入 | 份数 |
|---|---|---|
| C0 | 只给题目 | 7（全部角色） |
| C1 | 题目 + 3 行通用规则（区分事实/推断/建议；不确定要标不确定；不得编造文献） | 3（计算机、化学、医学） |
| S | 题目 + SKILL.md + 5 份 references（记录读取顺序） | 7 |

对照题（B 类短题，与主案例 B 不同）：从给定合成摘要判断"该方法是否已被证据支持"，要求指出最关键的缺失证据并给出下一步。

## 7 稳定性复跑

- 机器层：CLI 主套件完整 3 轮，比较 passed 集合、`stdout_sha256`、耗时离散度。
- 文本层：每角色 1 道新 C 类题 × 3 次（共 21 份，每次 ≤450 字），比较结构项集合的 Jaccard 与严重错误集合。
- 局限：同一模型、采样参数不可控、n=3；"3 次未发现矛盾"≠"稳定"。28 个主案例每题仅 1 次，此限制不得被掩盖。

## 9 效率口径

三层：解释器基线 T0（`python -X utf8 -c "import sys"` ×5 中位数）；9 条命令 ×3 次（500 卡库）；4 个规模 ×3 次 × 2 个版本。
口径声明（必须原样进报告）：下表为单位置进程启动与输出捕获的墙钟时间；不含 token、网络、真人操作，**不代表 Agent 响应速度，也不代表用户到达可用研究计划的时间**；Python 3.13 不在 CI 矩阵，结果不外推。

## 10 停止条件与失败处理

- 某题生成失败或明显不完整：如实记录「信息不足」，**不换题重试**。
- 某轮 CLI 出现 flaky：保留全部轮次，报 k/3，不重跑到全绿。
- 旧版探针因接口缺失失败：记 `note`，不改判定表。
- harness 自身缺陷：修 harness 后重跑，并在报告写明"harness 变更 + 原因"，`harness_sha256` 记录最终版本。
