# easy-research-skill 七专业评测报告（v4 · v1.2.1）

日期：2026-10-25　|　受测：`v1.2.1`（`0de1b93`）　|　分支/标签：`eval/stem-v4` / `eval-stem-v4`
执行者：7 个独立子 agent（每领域 6 题，共 42 题）+ 1 个无 Skill 对照 agent（7 题）

## 0 结论

1. **D 模式第一次被真实跑通**：7 个 agent 各自执行 `add --discipline/--research-type --set-extra` → `search` → `stats`，7 个库全部正确写入「学科 / 研究类型 / 2 个扩展字段」，无一例外。这是 v1.2.0 schema 在"别人手里"的第一次实证。
2. **对照臂第一次给出可归因的数字**：同样 7 道 B1 题，S 臂 `S1 6/7`、`S2 6/7`、`S6 6/7`，C0 臂分别是 `0/7`、`0/7`、`3/7`。差异集中在"标注结构"与"保留不确定"，**不在"阈值待设定"**（S 4/7 vs C0 5/7，无差异）。
3. **槽位覆盖打满**：50/50（v3 是 49/50），医学补上了"盲法"。但要注意——这是 6 道题摊开后的结果，不代表单个任务里槽位一定齐。
4. **机器层稳定**：26 探针在 v1.2.1 上 26/26（v1.2.1 只改了一行文档，与 v1.2.0 行为一致）。
5. **每个专业都点出了"材料最接不住的一题"**，且这 7 处几乎都不是措辞问题，而是缺判定条目：范围主张缺分母、HR 缺随访人时、节能缺基线可比性、准静态缺率效应、描述性研究缺季节与批次共线、类型表缺"记录/元数据"入口、`stats` 缺"按研究类型看"的视图。

## 1 方法

- 协议预注册（`protocol.md`）：7 学科 × 6 题 = 42 题，模式覆盖 A1/A2（两个方向）、B1/B2（两篇合成摘要）、C1（检验一个计划）、D1（真实 CLI）。
- 每个 agent 只读 `SKILL.md`、`references/research-types.md`、自己学科的 `disciplines/<学科>.md`；D1 允许且只允许写 `temp-data/role-<slug>.json`。
- 对照臂：取每题 B1（7 题），由一个**不读任何 Skill 文件**的 agent 回答，300 字上限。
- 测量：结构项（剔除 S4，因为 7 道题无共同关键词表）、槽位覆盖、S vs C0 对比、26 探针。

## 3 对照臂（本轮新增）

同一批 7 道 B1 题，两个臂的 8 项结构命中（S4 剔除）：

| 结构项 | S 臂（读 Skill） | C0 臂（无 Skill） | 差 |
|---|---|---|---|
| S1 事实/推断/建议分离 | 6/7 | 0/7 | **+6** |
| S2 新颖性状态显式 | 6/7 | 0/7 | **+6** |
| S3 无虚构来源 | 7/7 | 7/7 | 0 |
| S5 阈值标注待设定 | 4/7 | 5/7 | −1 |
| S6 保留不确定结论 | 6/7 | 3/7 | **+3** |
| S7 最小验证 ≥3 要素 | 1/7 | 0/7 | +1（代理失效，不计） |
| S8 不按占比评贡献 | 7/7 | 7/7 | 0 |

严重错误：两臂的 X1（虚构来源）都是 0/7。

**能说**：在 7 个指定案例、同模型、不同会话下，读 Skill 的回答更常出现"材料显示/我的推断/建议"的分栏（6/7 对 0/7），也更常明确写"未核实/未检索"（6/7 对 0/7），更常保留"信息不足"（6/7 对 3/7）。
**不能说**：不能换算成百分比，不能外推到其他模型或真实研究生；S5 上 Skill 臂并没有更好，这一条本轮**不支持**"Skill 提升了阈值纪律"。
**偏差披露**：S 臂 450 字上限、C0 臂 300 字，长度不对称，可能压低 C0 的结构项命中（尤其 S6）；下轮应统一字数。

## 6 跨专业缺口（v1.3 输入，按可修性排序）

1. **`stats` 增加按研究类型分组**（电子信息 D1 直接提出）：当前只能按学科/标签看，无法回答"我的预测类卡片有几张"。
2. **"范围主张"判定条目**（化学 B2）：主张"普适/通用"时，必须报分母 N、成功/失败分布、失败是否只在 SI。
3. **"时间可比性"槽位**（能源 B1、医学 B1）：基线期与报告期是否可比、随访时长与人时、失访率。
4. **"率相关/惯性"检查**（机械 C1）：准静态结论外推到冲击前，必须交代应变率、惯性与能量平衡。
5. **"记录/元数据"类型入口**（计算机 C1）：结构化实验记录既不是复现也不是预测，需要第四类"记录类"或归入工程验证的说明。
6. **描述性研究里的共线风险**（生物 A2）：季节、批次、测序轮次共线时的可识别性检查。
7. **降级阶梯**（v3 已提出，本轮再次被 5 个 agent 触及，仍未解决）。

## 7 限制

- 42 题仍是单次生成；D1 的 CLI 执行是真实的，但只覆盖"建卡/检索/统计"三步。
- 对照臂只有 7 题、字数与 S 臂不对称；结论只能按 k/7 报。
- 结构项 S7 依旧是失效代理（1/7 vs 0/7），S8/X2 在长文本上仍有假阳性（本轮 X2 3/7 已人工核对为表述误伤，不计入）。
- 离线、Windows、Python 3.13；不外推。
