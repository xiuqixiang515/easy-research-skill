# 七专业评测协议 v4（预注册 · v1.2.1）

跑题前冻结。本轮补充 v3 的两个缺口：**题量**（每领域 6 题）与**对照臂**（7 题无 Skill 对照）。

## 0 元信息

| 项 | 值 |
|---|---|
| 受测对象 | `v1.2.1`（`0de1b93`），学科 × 研究类型路由 |
| 执行者 | 7 个独立子 agent（每领域 6 题）+ 1 个无 Skill 对照 agent（7 题） |
| 分支 / 标签 | `eval/stem-v4` / `eval-stem-v4` |
| 环境 | Windows 11；Python 3.13.14；离线 |

## 1 边界声明（每份角色文件照抄）

1. 我是 2–3 年级研究生，在做真实决策（开题、投稿、组会、复现），不是领域评审人。
2. 我只评价"这套材料是否帮我做出可辩护的下一步"，不评价领域事实的真伪。
3. 未检索即未核实；不写"据我所知该方向已饱和"。
4. 不引用任何真实或伪造的文献标识；举例标「合成示例」。
5. 不给行业标准背书。
6. 每题只执行一次；单次输出不能作为稳定性证据。

## 2 案例矩阵：7 学科 × 6 题 = 42 题

模式：A 找 idea / B 拆论文（合成摘要）/ C 淬炼想法 / D 素材库（真实执行 CLI）。
每题针对的槽位见方括号。

### 2.1 计算机
- A1 只有一台笔记本（无 GPU）、10 周，做代码补全的评测偏差分析。〔切分、算力预算〕
- A2 想研究"数据增强对长尾类别的影响机制"。〔失败机制、机制可区分性〕
- B1 合成摘要：Few-shot 提示在 5 个任务上 SOTA，但 prompt 在验证集上人工调了 200 次。〔选择偏差〕
- B2 合成摘要：开源工具包称"复现 12 篇论文"，只报平均值不报逐篇差异。〔复现、报告完整性〕
- C1 想把"训练日志"改成"结构化实验记录"，称能提升可复现性。〔环境版本、可推翻条件〕
- D1 用 CLI 建一张卡（学科=计算机、研究类型、两个扩展字段），再检索与统计。〔扩展字段、可检索性〕

### 2.2 化学
- A1 只有分析天平、烘箱、UV-Vis，8 周，做固体催化剂负载量优化。〔计量、条件〕
- A2 想研究"溶剂对反应选择性的影响机制"。〔正交表征、条件控制〕
- B1 合成摘要：DFT 与实验产率趋势一致，但只算了一条反应路径。〔理论、机理边界〕
- B2 合成摘要：新方法称"普适"，底物表只列 6 个成功案例，失败案例放在 SI。〔选择性报告〕
- C1 想把"单批次"改成"三批次"就说明重现性。〔独立批次定义〕
- D1 CLI 建卡（单位/批次/仪器）+ 检索 + 统计。〔扩展字段〕

### 2.3 生物
- A1 只有 24 孔板和一台酶标仪，6 周，做药物浓度筛选。〔实验单位、重复〕
- A2 想做"微生物群落随季节变化"的描述性研究。〔抽样、代表性〕
- B1 合成摘要：RNA-seq 差异基因 2000 个，未做批次校正，称"发现核心通路"。〔批次、多重比较〕
- B2 合成摘要：动物实验 n=8，只报 p 值不报效应量。〔效应量、样本量〕
- C1 想用"同一批细胞传代三次"作为三个独立重复。〔重复类型〕
- D1 CLI 建卡（重复/批次/仪器）+ 检索。〔扩展字段〕

### 2.4 医学
- A1 只有 1 年门诊数据（约 800 人次），做罕见病变异筛查。〔人群、事件数〕
- A2 想做"某指标与生活方式"的横断面描述研究。〔抽样、测量〕
- B1 合成摘要：回顾性队列 HR 0.6，未说明随访时长与失访。〔因果、失访〕
- B2 合成摘要：诊断研究报"准确率 90%"，未报患病率与谱构成。〔谱偏倚、分母〕
- C1 想把"单中心"结果直接写成指南建议。〔外推、验证范围〕
- D1 CLI 建卡（t0/验证范围/仪器）+ 检索。〔扩展字段〕

### 2.5 机械
- A1 只有一台 3D 打印机和一台万能试验机，6 周，做点阵结构压缩性能。〔试样数、工况〕
- A2 想研究"残余应力对疲劳寿命的影响机制"。〔失效模式、机理解释〕
- B1 合成摘要：仿真与实验"吻合良好"（r=0.95），但样本 4 个且同一工况。〔收敛、样本〕
- B2 合成摘要：新材料"强度提升 20%"，试样取自同一块板，未报热处理批次。〔材料来源〕
- C1 想把"准静态"结果直接用于冲击工况。〔工况覆盖、率相关〕
- D1 CLI 建卡（单位/试样/仪器）+ 检索。〔扩展字段〕

### 2.6 能源
- A1 只有一栋楼的总电表和一个温湿度记录仪，10 周，做空调设定温度调整的节能评估。〔分项、边界〕
- A2 想研究"峰谷电价对储能调度的影响机制"。〔初末状态、边界〕
- B1 合成摘要：改造后"节电 18%"，用改造前一年做基线，未做天气修正。〔基线、混杂〕
- B2 合成摘要：LCA 报"碳足迹降低 40%"，功能单位中途改变。〔功能单位一致性〕
- C1 想把"夏季一个月"的结果写成年节电量。〔时间代表性〕
- D1 CLI 建卡（功能单位/边界/时间跨度）+ 检索。〔扩展字段〕

### 2.7 电子信息
- A1 只有直流电源、万用表、一块 MCU 板，6 周，做低功耗模式电流测量。〔带宽、测量本底〕
- A2 想研究"电源纹波对 ADC 有效位数的影响机制"。〔激励条件、本底〕
- B1 合成摘要：新 ADC 架构 SNDR 提升 6 dB，测试频率只有 1 kHz，采样率未报。〔激励条件〕
- B2 合成摘要：天线"增益提升 2 dBi"，对比天线尺寸不同、未报效率。〔公平性〕
- C1 想把"仿真 S 参数"直接写进测试报告。〔仿真-实测〕
- D1 CLI 建卡（单位/重复/仪器）+ 检索。〔扩展字段〕

## 3 对照臂（本轮新增）

- 取每题 **B1**（7 题）作为对照题；由**一个独立的对照 agent** 回答，**不读任何 Skill 文件**，仅给题面与 300 字上限。
- 对照臂与 S 臂同题、同模型、不同会话。
- 判读：只报结构项命中 `k/7`，不报百分比；对照臂命中即视为"模型自带能力"，不计入 Skill 增益。

## 4 测量

| 层 | 方法 |
|---|---|
| 结构项 | 8 项正则代理（沿用），作用域限定在回答正文，剔除文件头 |
| 槽位覆盖 | `slot_coverage.py`，按学科关键词统计每题命中 |
| 对照 | S 臂 vs C0 臂在 7 道 B1 上的结构项命中差（绝对计数） |
| 机器层 | 26 个探针在 v1.2.1 上跑一遍（v1.2.1 仅文档变更，不重跑基准） |
| D 模式 | 7 个 agent 实际执行 CLI，输出写入 `temp-data/role-<slug>.json`，命令与输出进角色文件 |

## 5 停止条件

- 某题答不出：写"信息不足"，不换题。
- 对照 agent 不接触任何 Skill 文件；若它自行发挥了专业细节，照实记录。
- 发现协议与实测不符：保留实测，报告单列。
