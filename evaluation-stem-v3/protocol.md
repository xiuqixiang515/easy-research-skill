## 1 边界声明（每份角色文件开头照抄）

1. 我是 2–3 年级研究生，在做真实决策（开题、投稿、组会、复现），不是领域评审人。
2. 我只评价"这套材料是否帮我做出可辩护的下一步"，不评价领域事实的真伪。
3. 未检索即未核实；不写"据我所知该方向已饱和"。
4. 不引用任何真实或伪造的文献标识；举例标「合成示例」。
5. 不给行业标准背书。
6. 每题只执行一次；单次输出不能作为稳定性证据。

**禁止表述**：提升 X%、有效率、准确率、更专业、专家背书、已适配七专业。
**允许表述**：本协议 k/n 例中出现/未出现。

## 2 与 v2 的去重

v2 已用 28 题（各专业 A 长尾评测/B 基准涨分/C batch/D 素材库等）。v3 每专业出 **3 道全新题**，子领域与失败机制均与 v1、v2 不同，且每题针对该学科文件里的 2–3 个必填槽位。逐题对照见各子 agent 的"槽位自检"。

## 3 案例矩阵（7 × 3 = 21 题）

统一附加约束：不得联网检索；不得编造文献、DOI、命中数；不确定处标注不确定。字数上限：A ≤ 900，B ≤ 700，C ≤ 700。

### 3.1 计算机（针对：切分单位 / 泄漏 / 算力预算）

- **A**：只有 4 张 3090 和一批未标注的运维日志，想做日志异常检测。请给方向与最小验证。
- **B**（合成摘要）：自有数据集 F1 0.91、公开数据集 0.72，作者称"方法通用"；未报划分方式、预处理流程与基线预算。
- **C**：我想把在线学习改成每夜全量重训，理由是"更稳定"。

### 3.2 化学（针对：身份与纯度 / 独立批次 / 计量定义）

- **A**：只有 GC-MS 和一台老化箱，12 周，做聚合物老化产物鉴定。
- **B**（合成摘要）：催化剂循环 10 次活性不降，作者称"多相催化剂稳定"；未做浸出测试与热过滤对照。
- **C**：反应温度 80→100 ℃ 缩短时间，转化率上升但选择性降 8 个百分点，我想说这条工艺更优。

### 3.3 生物（针对：实验单位 / 批次 / 重复类型）

- **A**：只有一个田间小区、两季材料，做品种抗性观察。
- **B**（合成摘要）：n=6，两批材料，处理与对照来自不同批次，结论称"处理提高抗性"。
- **C**：想用同一批样本再做一次 Western blot 作为重复。

### 3.4 医学（针对：t0 / 验证范围与事件数 / 因果越界）

- **A**：医院只有 3 年电子病历，想做再入院风险预测。
- **B**（合成摘要）：多中心 AUC 0.88，外部验证中心样本 40、事件 8 例，作者称"可直接推广"。
- **C**：我想对回顾性队列做倾向评分匹配，然后说"用药降低死亡率"。

### 3.5 机械（针对：收敛 / 多约束与可制造 / 试样数）

- **A**：一台疲劳试验机、2 个试样、10 周，做焊接接头寿命评估。
- **B**（合成摘要）：拓扑优化后质量降 30%，仅做静力校核，作者称"可直接制造"。
- **C**：想把仿真时间步放大一倍以加速，估计"结果差别不大"。

### 3.6 能源（针对：功能单位 / 初末状态 / 边界）

- **A**：只有建筑电费账单与空调铭牌，8 周，做空调群控节能评估。
- **B**（合成摘要）：光伏+储能系统"自给率 80%"，未报 SOC 初末状态、弃光率与边界。
- **C**：我想把"单位面积能耗"换成"单位床位能耗"作为主指标。

### 3.7 电子信息（针对：带宽公平性 / 测量本底 / 仿真-实测）

- **A**：只有一块 FPGA 开发板和一台 200 MHz 示波器，做电源完整性评估。
- **B**（合成摘要）：新调制在 SNR 5 dB 下 BER 优于对比方案 3 倍，但对比方案带宽只有其一半。
- **C**：我想用仿真眼图替代实测，理由是省时间。

## 4 测量

| 层 | 方法 | 判据 |
|---|---|---|
| 结构项 | 沿用 `grade_text.py` 的 8 项正则代理 + 人工抽查 | 只报 k/n |
| 槽位覆盖 | `slot_coverage.py`：按学科关键词表统计每题命中的必填槽位 | 与 v2 同专业角色文件对比，报"命中数/必填数" |
| 四维 | 角色自评（3 档 + 理由）+ 机器层证据（26 探针、CLI 3 轮） | 不打分、不排名 |
| 可靠性 | 26 个探针在 v1.2.0 与 v1.1.1 上各跑一遍 | 新探针应在 v1.1.1 红、v1.2.0 绿 |
| 稳定性 | CLI 套件 3 轮（若时间允许）；文本层不做重复，明写"未测" | 不得用单次输出推断稳定 |

## 5 停止条件

- 某题答不出或有明显缺口：如实写"信息不足"，不换题重试。
- 子 agent 之间不共享上下文；不互相引用结论。
- 发现协议与实测不符：保留实测，在报告单列一节记录。
