# easy-research-skill 七专业评测报告（v3 · v1.2.0）

日期：2026-10-25　|　受测：`v1.2.0`（`5b83e65`）　|　分支/标签：`eval/stem-v3` / `eval-stem-v3`
执行者：**7 个独立子 agent**，各自扮演一个专业的研究生（同一底层模型、不同会话、互不共享上下文）

## 0 结论

1. **工具层没有回归**：26 个探针在 v1.2.0 上 26/26；对照 v1.1.1 是 20/26，**6 项红→绿**（P21–P26 全部是新增的学科/研究类型能力）。CLI 集成 77 项 × 3 轮全绿，输出哈希跨轮一致。
2. **路由确实被用上了，但不是自动的**：7 份角色文件都主动列出了"本学科必填槽位"，并逐题做槽位自检；槽位关键词覆盖 v1.2.0 为 49/50，v1.1.1 为 47/50——**差 2 项，说明"术语出现"这件事本身不依赖学科文件**，学科文件改变的是"是否被逐项点名与交代"。
3. **最大的新发现是：槽位有了，降级路径没有**。7 个子 agent 里有 **5 个**在收尾时主动指出：当某个必填槽位在资源上填不上（只有一块板、2 个试样、无分项计量、无标签、8 个事件）时，材料只说"标为资源不足/信息不足"，**没说降到哪一档结论**。每个专业都自己发明了降级阶梯。
4. **结构项指标在本轮饱和**：S1–S8 全部 7/7，但人工复核发现 5 处假阳性（详见 §3.2）。因此**不能用它证明 v1.2.0 让输出结构变好**；本轮能支持的只是"工具层能力"与"槽位可被指名"。
5. **学科子槽位仍缺**：疲劳（R 比、焊趾几何、run-out 规则）、Eb/N0、不朽时间偏倚、分析物覆盖/仪器盲区、小区内空间梯度、制造工艺约束、铭牌值 vs 实测值——这些是 v1.2.1 的具体输入。

## 1 方法

- 协议预注册（`protocol.md`），7 学科 × 3 道新题 = 21 题，全部与 v1、v2 不重复；每题针对该学科文件里的 2–3 个必填槽位。
- 每个子 agent 只读 `SKILL.md`、`references/research-types.md`、自己学科的 `references/disciplines/<学科>.md`（不读其他学科，模拟按需加载），每题单次生成。
- 角色文件统一结构：边界声明 → 必填槽位 → 三题（题目/回答/槽位自检）→ 四维评价 → 规则缺口（带行号）→ 结论与限制。
- 机器层：26 探针 × 2 版本；CLI 套件 × 3 轮。
- 文本层：沿用 8 项结构项正则 + 新增"槽位关键词覆盖"与"降级声明计数"；不设无 Skill 对照（见 §6）。

## 4 七专业逐条

| 专业 | 这一轮最有用的地方 | 最缺的一处 | 子 agent 自述最不满意 |
|---|---|---|---|
| 计算机 | 把"无标签"逼成显式假设，而不是假装有训练集 | 无"弱监督/无标注"类型段，标签来源无处安放（`research-types.md:6-19`） | 题 A：材料只给"有标签"的槽位表，注入协议得自己造 |
| 化学 | "循环活性≠多相"这类替代解释被点名 | 缺"分析物覆盖/仪器盲区"槽位（`chemistry.md:6-17`） | 题 A：把"鉴定"降级成"趋势"是资源逼出来的，材料没给换目标的规则 |
| 生物 | 批次混杂被判成"0 个可比批次"，比"2 批=2 重复"更进一步 | 生物学重复的正面定义缺失（`research-types.md:41` 只写越界） | 题 C：换管/换提取/换个体/换批次，哪一档算重复没有定义 |
| 医学 | t0 与"出院后变量不可用"被直接写进方案 | 验证范围没有"单中心小样本外部"档；事件数只问"够吗"（`medicine.md:25-27`） | 题 B：只好自造"外部抽检"这个档位 |
| 机械 | 2 个试样被判"只能做单点标定"，没有硬凑统计 | 缺疲劳专槽：R 比、焊趾几何、run-out 规则（`mechanical.md:8-16`） | 题 A：疲劳判据只能从"3 根"那条间接推 |
| 能源 | 无分项计量时主动改口径为"总表 + 区间" | 缺"铭牌值 vs 实测值"、"最低可接受时间跨度"（`energy.md:12,16`） | 题 A：空调占比只能靠铭牌×假设负荷率，区间宽到可能跨零 |
| 电子信息 | 一块板就把结论降到"该板该次上电" | 公平性只到带宽/功率，缺 Eb/N0 层（`electronics.md:12`） | 题 A：S7 物理上填不了，材料没给降级到哪一级 |

## 5 跨专业共性缺口（v1.2.1 的输入）

1. **降级阶梯缺失**（5/7 主动提出）：现有规则只有"标为信息不足/资源不足"，没有"降到哪一档"的映射。建议在 `research-types.md` 增加一张"槽位缺失 → 结论降级"表，例如：缺重复 → 只能给单点观测；缺事件数 → 只报区分度不报校准；缺分项计量 → 只报总表区间；缺校准 → 结论限定在该板该次。
2. **路由入口不全**（2/7 提出）：模式表没有"无标注/弱监督"、"更换功能单位/主指标"、"评估外部主张 vs 自身方案"的词条，使用者要靠猜。建议给模式表加"变更类"入口，或在 `research-types.md` 补"方法改进/工艺决策"两类。
3. **学科子槽位不足**：疲劳、Eb/N0、不朽时间偏倚、分析物覆盖、空间梯度、工艺约束、铭牌 vs 实测——每一条都是该专业判断的支点。
4. **文件间定义冲突**：`research-types.md:39` 把"独立批次"当重复来源，`biology.md:12` 把"批次"当混杂来源，同一件事两个角色，没有仲裁说明。
5. **降级后目标怎么重写**：化学的"鉴定 → 趋势"、机械的"寿命 → 单点标定"，都是换研究目标，而不只是标注缺陷；材料缺少"重写目标"的动作词。
