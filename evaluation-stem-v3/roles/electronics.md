## 2 题 A（FPGA 板 + 200 MHz 示波器做电源完整性）

### 2.1 题目

只有一块 FPGA 开发板和一台 200 MHz 示波器，想做电源完整性（PI）评估，要方向与最小验证。

### 2.2 原始回答

**能做，但只能做到"单板、≤200 MHz、时域纹波 + 低频阻抗"这一级。你的天花板不是被测件，是探头和地环路。**

「材料显示」`electronics.md:15` 把"测量链本底"列为必填，`electronics.md:26` 把"测得 10 bit 接近理论值"判为未扣本底。「我的推断」这条对纹波同样成立：探头地弹簧的长地回路会把开关噪声当被测信号收进来，200 MHz 探头在 100 MHz 以上幅度与相位都开始失真。

**方向（顺序别跳）**

1. **先测本底，再测板子。** 探头尖端短接到地弹簧、50Ω 直通、探头自身频响。先知道"什么都没接时读到多少 mVrms"，否则后面每个纹波数字都含这个底。
2. **时域法（可行，先做这个）。** AC 耦合 + 20 MHz 带宽限制测 DC 纹波；用 FPGA 内部逻辑做可控翻转负载（改翻转率、改翻转位置），测 Vcore 的 ΔV 峰峰值与恢复时间。
3. **注入法（有条件可行）。** 信号源串电阻注入，双通道同时测注入点电压与串联小电阻上的电流，扫 1 kHz–200 MHz 得 |Z|。夹具与探头不去嵌，误差可能大于你想看的差别——所以这一步的结论只能写趋势，不能写绝对值。
4. **不要做的。** 不要声称覆盖 PDN 全频段。核心电源噪声能量大量落在 100 MHz 以上，200 MHz 只是下沿。「尚未核实」你板上的具体频段分布，取决于器件与负载谱，得自己用负载谱估，我不能替你断言。

**最小验证（一次做完，约半天）**

- 步 0 本底：探头短接，5 次上电各测一次噪声底，记极差。
- 步 1 静态：目标轨，AC + 20 MHz，峰峰值，5 次上电。
- 步 2 动态：翻转率取低/中/高三档，每档测 ΔV 峰峰与恢复时间。
- 步 3 判据：允许纹波与 Ztarget **待设定**。怎么选——从器件手册的 Vmin/Vmax 与负载电流阶跃算 ΔV_allowed 再除 I_step；手册拿不到就先用现有设计实测纹波当基线，别拍数。本步我做不了，因为「未核实」你用的器件。
- 步 4 结论只写："该板在该负载谱下、≤200 MHz 观测窗口内，纹波为 X"，不外推。

「建议」真想看高频，借一台 VNA 或 1 GHz 以上探头，比在 200 MHz 上硬撑便宜——这是成本判断，不是证据。

### 2.3 槽位自检

- **填了**：S1（纹波峰峰、|Z|，并声明参考带宽只到 200 MHz）；S2（翻转率三档、注入频率与幅度）；S5（去耦、地环路、探头接地方式）；S6（步 0 独立成步）；S8（本题不涉仿真，标"不适用"而非"已填"）。
- **没填**：S3（无对比方案，不适用）；S4（只有负载谱，没有噪声/信道模型）；S7（只有一块板，板间维度物理上缺失——这是本题最大硬伤，所有结论只能限定"单板"）。
- 因 S7 缺失，「我的推断」这一步的结论强度只到"该板该次上电"，连"该型号"都到不了。

## 3 题 B（合成摘要：SNR 5 dB 下 BER 优 3 倍，对比方案带宽仅一半）

### 3.1 题目

（合成摘要，非真实论文）新调制在 SNR 5 dB 下 BER 优于对比方案 3 倍，但对比方案带宽只有其一半。评估其主张。

### 3.2 原始回答

**这条主张现在不成立。不是因为调制不好，是因为记账方式不对。**

「材料显示」`electronics.md:12` 要求核"对比方案是否同带宽、同发射功率、同采样率"，`electronics.md:24` 直接把"BER 从 1e-3 降到 1e-4，方案更优"列为错误结论、追问"同带宽同功率重测了吗"。这条摘要正落在这个格子里。

「我的推断」三处硬伤：

1. **同 SNR ≠ 同 Eb/N0。** 对比方案带宽只有一半，符号率不变时它的 Eb/N0 比新方案低约 3 dB。BER 差 3 倍在瀑布区大约对应零点几到一点几 dB 的 Eb/N0 差（具体看调制与编码，「未核实」，要它给曲线自己读）。这 3 dB 很可能吃掉全部或大部分优势——那是带宽换的，不是调制换的。
2. **"3 倍"没有绝对值。** 1e-3→3.3e-4 和 1e-2→3.3e-3 都叫 3 倍，工程含义差一个数量级。「材料显示」`electronics.md:10` 要求写清 BER 怎么算、参考带宽多少，摘要都没给。
3. **单点。** SNR=5 dB 一个工作点，没有瀑布曲线，分不清是曲线平移还是斜率变化。只有斜率变化才更像调制/编码的真实增益。

「建议」要它补四样才可判：等带宽等功率等符号率重测；BER 绝对值 + 蒙特卡洛次数（决定置信区间）；BER vs Eb/N0 至少 3 点；代价侧（峰均比、复杂度、时延、bit/s/Hz）。

若只保留现配置，能说的只有"在该带宽配置下新方案 BER 更低"——这是描述，不是"调制更优"。`SKILL.md:51` 的意思是缺项要写出它限制了哪条结论：缺 S3，所以"更优"只能判为信息不足。

### 3.3 槽位自检

- **填了**：S1（指出 BER/SNR 口径未给，据此判不可比）；S2（SNR 5 dB 单点，符号率未知）；S3（核心，判定为不公平）；S8（摘要未说明仿真还是实测，标"未核实"）。
- **没填**：S4（只有 SNR 数值，无噪声/信道模型）；S5（摘要未提，无法判断是否含同步损失）；S6（非测量类，标不适用）；S7（未提独立实现数/种子数/试验次数）。

## 4 题 C（用仿真眼图替代实测，理由省时间）

### 4.1 题目

想用仿真眼图替代实测，理由是省时间。检验这个替代是否成立。

### 4.2 原始回答

**"省时间"是成本理由，不是证据理由。可以用仿真，但不能用它下"链路能跑"的结论。**

「材料显示」`research-types.md:44-49` 把仿真越界写成"把'与实测接近'当'模型正确'"、"单工况单网格外推到设计"，必需项含"校核数据"。`electronics.md:17` 直接问仿真是否含寄生、容差、时钟抖动，缺失后果是"仿真结论不能当实测"。`electronics.md:25` 把"仿真 SNR 提升 3 dB 可投论文"列为错误结论。

**能替代的**（「我的推断」）：给定信道下的调制/均衡/CDR 算法行为；你显式注入的抖动（DCD、周期性抖动）与噪声；参数扫描与设计空间探索——这块确实省时间，实测做不了这么密。

**替代不了的**：信道本身。眼图闭合主因是 ISI，ISI 来自插损、反射、过孔。仿真里的信道模型若不是你这块板的实测 S 参数，画出来的是别人的眼图。以及 RJ、电源噪声耦合、温漂、批次容差、连接器寄生。`research-types.md:96` 写明"仿真不能证明可制造"——同理，仿真不能证明链路可用。

**最小验证（便宜到贵）**

1. **收敛**：比特数加倍，眼高/眼宽漂移小于某值才停。该值**待设定**；选法——取判据裕度的 1/10（眼高裕度 50 mV 就要求漂移 <5 mV），或直接要求两次翻倍之差小于你的重复性。
2. **敏感性**：RJ 参数、插损、终端电阻各两档，蒙特卡洛，看眼图是否被判据切开。
3. **校核（这一步不能省）**：找一条能实测的信道，同条件实测一次眼图，与仿真对比，得到"仿真−实测"误差带。没有这个误差带，仿真结果只能叫"模型内可行"。
4. 「建议」如果一次实测都排不进去，就把结论写死成："在给定信道模型与抖动假设下裕度为 X，未经实测校核。"别写"链路可用"。

顺带一句：省下来的时间如果没换成"多做两种信道/两种容差"，那省的就是没法用在结论上的时间。

### 4.3 槽位自检

- **填了**：S8（本题核心）；S1（眼高/眼宽/对应 BER 必须与模板口径一致）；S2（码型阶数、速率、幅度要在仿真里写死）；S5（CDR、CTLE/DFE 参数设定）；S4（要求信道模型来源）。
- **没填**：S6（仿真侧不适用，但校核那一侧的实测本底必须补，本题没做）；S3（无对比方案，不适用）；S7（没给种子数/蒙特卡洛次数——这是仿真版的"重复"，缺失，所以"眼图收敛"这句本身只有单次证据）。

## 6 规则缺口

1. **`SKILL.md:19` 的模式映射不全。** "评估他人已有的主张"（B 题）和"检验自己的替代方案"（C 题）在模式表里没有对应词条，只有"拆论文/淬炼想法"。摘要不是论文、替代方案也不完全是想法的情形，靠使用者猜。建议在模式表补一行"评估外部主张 → B；评估自身方案的可行性 → C"。
2. **`electronics.md:12` 漏了 Eb/N0 这一层。** 槽位只问"是否同带宽同功率同采样率"，但 B 题真正的陷阱是"同 SNR 不同带宽 ⇒ Eb/N0 差 3 dB"。公平性检查停在物理量层面，没到能量每比特层面，正好被这类摘要钻过去。
3. **`electronics.md:17` 的 S8 只查"仿真是否含非理想因素"，没查"仿真是否被实测校核过、误差带多少"。** 这是勾选式检查，C 题的核心恰恰是校核而不是清单。`research-types.md:46` 有"校核数据"这一项，但学科文件没把它落到具体追问上。
4. **`electronics.md:6-17` 八项全"必填"，没有资源受限时的降级路径。** `SKILL.md:65` 说"资源不足直接标资源不足"，但没说降级到哪一级结论。A 题只有一块板，S7 物理上不可能填，材料没告诉我该把结论降到"单板单次"还是"不可评估"。

## 7 结论与限制

1. 这套材料的真实价值是**降级器**而不是**答案机**：它不告诉我 PDN 怎么测、眼图怎么校核，但能在我几乎要写"仿真可以替代实测"的时候把这句话按住。对我这个阶段够用。
2. 它对"公平性"和"本底"的敏感度明显高于一般 checklist，这两条正好是电子信息方向最容易被审稿人打的地方，算是选对了重点。
3. 缺口集中在**方法层**：8 个槽位都是"要问什么"，没有"怎么测"。刚入门的人拿到手会知道缺什么，但不知道怎么补；2–3 年级能自己补，所以边际收益随年级下降。
4. 全篇没有数值阈值，是刻意的设计（避免伪造标准），我认可这个取舍，但实际写作成本不低——三题里 3 处"待设定"都要自己论证选法。
5. 上述判断基于三份文件各读一遍、单次作答，未做重复执行，**不能作为稳定性证据**；且这是 AI 扮演的研究生视角，不等于真人研究生的判断。
