## 1 本学科必填槽位（摘自 biology.md 第 1 节）

| 槽位 | 必填 | 缺失后果（原文要点） |
|---|---|---|
| 实验单位 | 是 | n 指个体/孔/皿/窝/田块；单位错位使统计检验整体失效 |

## 2 题 A

### 题目
只有一个田间小区、两季材料，想做品种抗性观察。给方向与最小验证。

### 原始回答

先摆硬约束。**材料显示**（biology.md:10-12）"实验单位"和"批次"是必填槽位。你现在是 1 个小区、2 季，田块层面 n=1，季节层面 n=2 且与年份完全绑定。

**我的推断**：这两季不能互相当重复。同一块地的菌源基数、土壤带菌、肥水、前茬在季间是连续的，第二季带着第一季的残留，不是独立抽样。严格意义的品种抗性比较立不住：品种间比较要求每品种至少两个独立小区，你没有。

三个方向，按可落地性排：

**① 降级为描述性（最稳）**。写"某品种在本小区两季的病害进展描述"，明确不做品种间推断。research-types.md:58-63 要求抽样框、代表性、精度——你能给的是小区内多点取样，"代表性"只能声明天花板（单点、单地、单年型），不能外推。

**② 如果小区里其实分行了**：把"行"当实验单位，但要承认行间不独立（相邻行共享菌源与肥力梯度），只报效应量+不确定度，不做显著性强的断言。这是把 1 个 n 拆成 k 个伪重复：提精度，不提推断力。

**③ 加一个已知抗/感对照品种，哪怕只一行**：没有参照，抗性高低没有坐标。此品种是否真抗，**尚未核实**，需你按本系统已有认知确认。

**最小验证（建议这样排）**

- 测量协议先定再下地：病级分级标准、每行 5–10 个取样点、避开边行 ≥2 行、同一人同一时段测、测者不知道行对应哪个品种。盲法是你唯一能低成本填满的必填槽位（biology.md:13）。
- 时点：至少两次，间隔按本系统潜育期定——**待设定**。选法：用你田里"最早显症"到"普遍显症"的实测间隔，别抄别人的天数。
- 判据：不要设"发病率 < X% 即抗"。**待设定**。选法建议：先算同一品种内各取样点的变异系数 CV，把"品种间差值 > 2×CV"当最小可分辨差异。CV 用你本季数据算，不依赖外部数字，阈值因此有本地依据。
- 记录：品种编号/种子来源。资源身份虽标"建议"（biology.md:15），对多年跟踪的题几乎是必填。

**未核实**：我不了解你作物-病害系统的病程速度与分级惯例，上述时点与分级必须按你的系统改。

### 槽位自检

- **填了**：实验单位（田块→行→取样点，明确三级）、随机化与盲法（测者可盲，分组不随机但已声明）、统计方案（放弃显著性主比较，改为 CV + 最小可分辨差异）。
- **没填**：重复类型（无生物学重复，季内多点只能算技术性重复）；批次（两季不独立且与年份混杂，等于 0 个可比批次）；样本量依据（无功效估计，只能事后报 CV）；资源身份（视你是否留了品种编号）。
- **没填的原因**：这四项是资源本身不提供，不是我漏填；按 SKILL.md:40 未用推测填满，结论相应降级为"描述性观察 + 待验证方向"。

## 3 题 B

### 题目
（合成摘要，非真实论文）n=6，两批材料，处理与对照来自不同批次，结论称"处理提高抗性"。评估其主张。

### 原始回答

致命处不是 n 小，是处理和批次完全重合。

**材料显示**：n=6、两批、处理与对照不同批。

**我的推断**：若处理组全在批 1、对照组全在批 2，"处理效应"与"批次效应"在数据里是同一个变量，没有自由度能分开。这不是"证据弱"，是**结构上不可识别**。差异再大也不能归给处理。

缺失的必填槽位（biology.md:10-14）：实验单位（6 是个体、皿还是孔，摘要没说）、重复类型（生物学还是技术，没说）、批次（名义 2 批，但处理/对照不平衡，等于没批）、随机化与盲法（未提）、统计方案（未提）、样本量依据（未提）。

判断分三层：

- **材料显示**：作者报了 n=6 和"提高抗性"。
- **我的推断**：这批数据无法区分处理与批次；应判"不可识别"。注意这不等于"处理无效"——research-types.md:51 明确不能因缺对照/方差就断定方法无效，反向同理，也不能因差异大就断定有效。
- **尚未核实**：效应量、不确定度、批内重复结构摘要都没给，连"差异是否存在"都无法确认。

**可辩护的下一步（建议）**

1. 重做时每批内部都要有处理与对照，批次当区组。批间差异被区组吸收，处理效应才有残差可估。
2. n 的口径先写死：6 是 6 个独立个体 / 独立孔 / 独立批次？同一批材料分 6 孔属技术重复，标准误会低估（biology.md:11）。
3. 判据不设固定百分比（**待设定**）。选法：用批内对照组的 CV 定最小可分辨差异，处理-对照差值需超过它。
4. 无法重做时，此结果只能作为提示性观察，不能当你开题的证据基础。

### 槽位自检

- **填了**：批次（识别为完全混杂，判定不可识别）。
- **没填**：实验单位、重复类型、随机化与盲法、统计方案、样本量依据、资源身份——全部因摘要未给。按 SKILL.md:40 降级为"信息不足"，未替作者补全。

## 4 题 C

### 题目
用同一批样本再做一次 Western blot 作为重复，检验这个做法。

### 原始回答

"同一批样本再做一次"至少有四种读法，证据强度差很远：

1. 同一管裂解液，重新上样跑新胶——纯技术重复，测的是上样、转膜、曝光、抗体批次的波动。
2. 同一块组织重新裂解定量——仍是同一生物学单位，只多一层提取变异。
3. 同一批材料的不同个体/不同孔——可能算生物学重复，取决于取样时是否独立。
4. 新一批材料（新一季、新传代）——唯一能覆盖批间变异的重复。

**材料显示**：biology.md:11-12 把重复类型与批次都列为必填；research-types.md:41 把"技术重复当独立样本"列为越界。**我的推断**：你说的做法落在第 1 或第 2 种，不能当独立重复用。

**它能合法做什么（建议）**

- 估测量误差：同管裂解液跑 3 次，算内参归一化后灰度的 CV。这个 CV 是判断"组间差 20% 算不算真差异"的分母。
- 排除单次假象：首次条带可疑时重跑属复核，不是增加 n。
- 换抗体批号重跑看信号是否稳定（抗体 RRID 是建议槽位，biology.md:15，但这题里它直接影响解释）。

**不能做的**：写成"n=3 独立重复"；用它把首次不显著"跑到显著"；两次里挑好看的那张。前两条正是 research-types.md:41 的越界，第二条还叠加了事后选择。

**判据（待设定）**：我没有你靶蛋白的合理 CV 范围，不编数字。选法建议：先跑 3 次同管样本取归一化灰度 CV；若 CV 已接近预期组间差异的一半，说明读出系统分辨不了目标效应，应改定量方式（换近红外、加 qPCR 旁证），而不是继续加跑。另需固定：上样量、内参、曝光是否饱和、剥离重孵还是新膜。新膜等于一次新测量，剥离重孵重复性通常更好但损耗抗原——此点**未核实**到你的系统。

### 槽位自检

- **填了**：重复类型（判为技术重复）、批次（同批，批间未覆盖）、实验单位（样本/个体，需你确认取样是否独立）。
- **没填**：随机化与盲法（WB 定量可盲，但你没说做不做）、统计方案（无预设主比较）、样本量依据（无）、资源身份（抗体 RRID 未知）。原因是这些取决于你的实验记录，材料里没有。

## 6 规则缺口

1. **`references/disciplines/biology.md:10-16`** 槽位表没有"时点/病程阶段"和"小区内取样位置"。题 A 里这两项直接决定读数，只能硬塞进"实验单位"，一塞就丢了"同一小区内空间梯度"这层信息。
2. **`references/research-types.md:39` 与 `references/disciplines/biology.md:12` 对"批次"的定义冲突**。类型表把"独立批次"当重复来源，学科表把"批次"当混杂来源。题 B 正好卡在中间：作者可能自认 2 批=2 重复，按学科表其实是 0 个可比批次。两份文件没有一句说明这个冲突怎么处理。
3. **`references/research-types.md:41` 只写了越界，没给正面边界**。"技术重复当独立样本"是错的，但换管、换提取、换个体、换批次，哪一档才算生物学重复，没有定义。题 C 我只能靠推断补，材料没兜住。
4. **`SKILL.md:80-82`（模式 C）缺"资源不足"降级路径**。模式 A 在 `SKILL.md:65` 有这条，模式 C 只有"信息缺失时追问"。题 C 若样本量本就不够，材料不会告诉我该判"资源不足"还是"信息不足"。
