## 题 A：两条八周内可检验的方向

### 完整题目

我是生物研究生，想利用既有公开、非敏感表达数据，在 8 周内研究应激相关机制。请给出 2 个可检验的研究方向，说明各自的假设、数据要求、比较基线、主指标、反例或停止条件、成本与缩小方案。不要编造数据集、论文或实验结果。本次不能联网，也不运行脚本。

### 实际按 Skill 生成的回答

可以先把目标定为“筛出经公开数据支持、可被推翻的机制候选”。仅靠表达关联不能完成因果机制证明；8 周的合理交付是有清楚证据边界的候选与验证设计。

**材料显示：** 你有 8 周，限定使用既有公开、非敏感表达数据；没有给出物种、应激类型、数据编号或样本表。

**暂用假设：** 先限定一种物种、一种组织或细胞系统、一类应激；优先使用已整理表达矩阵与样本元数据。两项假设均不是你已确认的资源。如果只有单个时间点，方向 1 的时间顺序问题不能按原设计检验；如果缺独立样本和关键元数据，不能按方向 2 声称已排除混杂。

**尚未核实：** 本次没有检索或检查任何实际表达数据。下述数据条件是入选标准，不代表已有符合条件的数据。两个方向的新颖性均为“未核实”，不能写成首次发现。

| 要素 | 方向 1：应激应答与恢复的时间分离 | 方向 2：候选表达信号是否由细胞组成或批次解释 |
|---|---|---|
| 场景与具体问题 | 在同一系统的应激及恢复时间序列中，候选基因集的变化是否先于预先定义的恢复指标？要检验“终点差异表达等同恢复机制”的简化解释 | 在同一系统的应激与对照表达数据中，候选基因集的应激关联，在控制可辨识混杂后是否仍存在？要检验“总体表达差异即细胞内机制”的简化解释 |
| 待检验假设 | 指定候选表达分数的早期变化，与稍后恢复相关表达指标存在可重复的时间关系；这只是时序关联假设 | 候选表达分数与应激的关联不能完全由已记录批次及估计组成变化解释；残余关联仍不是因果证明 |
| 数据入选条件 | 有应激、匹配对照、多个时间点及恢复条件；有真实独立生物样本；能区分重复测量与独立个体。优先选择有独立功能恢复读数的数据；若只有表达，明确只测恢复相关表达 | 有足够的独立样本、应激分组、批次及关键协变量；组成估计还需要与该组织相符、可核对的参考。若应激与批次完全重合，应视为设计不可识别，不能靠回归“修正成功” |
| 现有做法与差异 | 与只比较单一终点差异表达相比，增加时间顺序、恢复对照和独立数据验证；没有预设这些方法在领域中尚未被用过 | 与不调整的差异表达／相关分析相比，显式比较未调整与调整结果，并检查设计是否可识别、组成估计是否稳健 |
| 工具与基线 | 建议用与数据类型相符的表达模型：原始计数和已归一化矩阵不能混用同一种输入假设。比较终点模型与包含时间、条件及其交互的模型；重复测量按个体处理 | 建议比较未调整模型、加入预设协变量模型、以及加入可信组成估计的模型。记录版本及输入；不把“最复杂模型”自动当成正确基线 |
| 主指标 | 预设候选分数的条件×时间效应及区间；预设一个早期分数与后续恢复指标的时间关系作为独立验证目标，避免在发现集里任意挑时间点 | 预设候选分数的调整后应激效应及区间，并报告相对未调整结果的变化 |
| 辅助指标与验证 | 不同独立样本／独立数据的方向一致性、批次敏感性；若有功能读数，检验表达与功能恢复是否一致。发现集选出的基因集不能在同一批样本上当成独立验证 | 组成估计方案和协变量选择的敏感性、独立数据中的效应方向及区间；表达估计的组成有测量误差，不能称已排除所有混杂 |
| 判据与反例 | 检验前按领域意义与测量精度设定最小效应，当前阈值待设定。若独立验证不支持预设时间关系，削弱该候选；若区间过宽则结论不确定。没有时间点／恢复元数据则停止此问题 | 检验前设定最小效应及区间判据，阈值待设定。若调整后效应接近预设无实质差异范围，且估计精度足够，削弱“独立于组成”的解释；若精度不足则不确定。关键混杂不可辨识时停止该解释 |
| 成本、风险与缩小 | 已整理矩阵可降低下载与处理负担；样本表核对、设计与敏感性分析仍占主要工作。只做一个系统和一个预设候选基因集；不要将多个时间点当独立生物重复 | 可先做一个应激对比、一个候选基因集、少量有理由的协变量。若没有合适组成参考，缩小为“批次与已记录协变量的稳健性分析”，不补造组成信息 |

**建议的八周安排：** 第 1 周核对数据来源、许可、样本独立性和可识别性；第 2 周冻结问题、主要对比、候选定义、排除规则及分析计划；第 3–4 周完成发现分析与质量核查；第 5–6 周做预设验证和敏感性分析；第 7–8 周整理全部结果、负结果及局限。优先在第 1–2 周只选定一个方向作为主线，另一方向作为有条件的备选，避免把两套完整研究都塞进八周。

**停止与退路：** 第一周发现没有符合入选条件的数据，先缩小主张，不继续承诺机制研究。独立验证缺失时，交付探索性关联结果和后续证据链；不能把同一数据反复切分包装成新的独立生物复现。

## 题 B：合成论文的证据拆解

### 完整题目

请评审下面这篇合成论文材料，不把它当成真实已发表论文：作者把同一培养样本分成 3 孔，将 3 孔当作 n=3，报告单次差异表达和相关性，进而声称“基因 X 导致表型 Y”，但没有独立生物重复。请区分作者声称、实际做法、可能贡献与证据限制，说明结论能支持到哪里；不要补造全文或实验。

### 实际按 Skill 生成的回答

本质是：**单次培养中的表达关联，被扩写为因果结论。**

**材料显示：** 这里只有用户提供的合成描述；同一培养样本分成 3 孔、没有独立生物重复、仅报告单次差异表达及相关性。没有原始数据、完整方法、效应量、区间、干预设计或论文全文。因此以下结论只针对这个描述，不是对一篇真实论文全部证据的判断。

| 论文主张 | 材料中实际做法 | 可能的增量 | 证据强度 | 限制或待查 |
|---|---|---|---|---|
| 存在稳定差异表达 | 同一培养来源的 3 孔，单次差异表达 | 可以产生该次培养内的候选表达差异；具体差异是否存在无法核实 | 不足：不能据此推及独立培养或更广泛生物变异；具体数值无法判断 | 需要样本与分组表、培养批次、测量层级、处理分配方式、数据质量和多重比较处理 |
| X 与 Y 存在可推广关联 | 单次相关分析 | 可以提出待独立验证的 X–Y 关联假设 | 不足：缺独立样本，无法证明跨培养可重复的关联；具体相关计算是否正确无法判断 | 相关分析究竟跨什么单位、有没有同一来源伪重复、是否批次／细胞状态共同驱动、是否筛选后再检验 |
| X 导致 Y | 用表达变化与相关性支持因果 | 材料没有显示可确认的因果增量；不等于真实论文必然无创新 | 不足：未显示能区分 X→Y、Y→X 或共同原因的设计 | 缺方向性干预、时间关系、特异性控制和独立生物重复；需要与其声称的因果范围相称的证据 |
| 已说明作用机制 | 描述中未提供中介环节或通路验证 | 无法判断是否有其他机制证据 | 无法判断其他机制证据；仅凭所述证据不足 | 即使未来 X 的干预改变 Y，也需要进一步验证所声称的中间路径，不能自动写成完整机制 |

**我的方法学推断：** 按题设“同一培养来源、没有独立生物重复”，这 3 孔不能被写成 3 个独立生物重复；应报告一个生物来源内的孔级重复及其层级。孔间变异不能替代独立培养间的生物变异。仍需核对分孔、处理分配与测量流程：如果处理独立随机分配到孔，孔可能是该次培养内某项处理比较的实验单位，但这不会自动产生跨培养的独立生物重复，也不解决因果机制主张。不能只看“3 孔”三个字就断言所有统计比较均无效。

**当前可以写的结论：** “在所描述的单次培养体系中观察到候选表达差异及 X–Y 关联，作为进一步独立验证的线索。”由于没有实际数据，连这一观察的数值正确性也尚未核实。不能写“已证明 X 导致 Y”或“已阐明 X 的作用机制”。

**建议：** 首先把样本层级和实验单位报告清楚；保留全部数据并把结论降为探索性。随后用独立培养或适合研究对象的独立生物来源进行验证，按来源／批次建模；技术孔可改善测量精度，但不要用增加技术孔冒充生物样本量。是否需要多少独立重复，应依据预设效应、方差与精度或功效目标决定，不能把“n=3”当作通用合格线。因果结论还需题 C 所述设计。未检索相关工作，因此不评价“首次”“创新不足”或“别人早做过”。

## 题 C：从相关基因到最小因果证据链

### 完整题目

我从表达分析中发现了相关基因 X，想直接写“X 通过某机制导致表型 Y”。请帮我设计最小证据链，指出什么结果支持、削弱或不足以判断这个主张。只讨论研究设计，不写实验操作配方、试剂浓度、培养条件或逐步操作。

### 实际按 Skill 生成的回答

目前只能把 X 当作候选。需要先区分两项主张：“改变 X 会影响 Y”和“X 通过指定路径 M 影响 Y”；第二项需要比第一项更多的证据。下面给出设计框架，M 是待提出并验证的中介占位符，不是我替你确认的机制。

**材料显示：** 已有 X 与 Y 的表达关联；没有提供物种、系统、Y 的定义、扰动证据、独立重复或具体中间环节。

**五段式假设：** 在明确的研究系统及应激条件中，比较随机分配的 X 定向扰动与匹配对照，检验预先定义的 Y 是否改变；相较单纯表达相关，方向性干预更能区分部分替代解释；若干预确实改变 X，但 Y 的效应区间排除预设有意义效应，则削弱该条件下的 X→Y 主张。具体系统和效应阈值待填，不能把通用框架当成已经可执行的定案。

| 证据环节 | 最小设计及对照 | 支持什么 | 什么会削弱、停止或仍不确定 |
|---|---|---|---|
| 1. 可靠观察与单位核对 | 在独立生物来源复核 X–Y 关联，核对批次、处理与时间信息；预先定义 Y 的直接表型读数，避免仅用同一表达矩阵中选出的基因分数替代 Y | 确定候选值得进入干预验证；不支持因果 | 关联不能复现会降低优先级；样本量不足或区间过宽仍不确定。不要用“相关复现”直接跳到机制 |
| 2. 定向干预及时间顺序 | 在独立生物来源内随机分配 X 扰动与匹配对照；比较应激／非应激条件以检验情境依赖；能盲法的结局评估采用盲法。确认 X 的改变发生在 Y 变化前，并测量干预是否真正达成 | 在该系统和干预条件下，支持 X 对 Y 的因果贡献；不自动证明普遍必要或充分 | X 没有被有效改变时，Y 不变不能反驳假设；X 已可靠改变且有足够精度排除有意义 Y 效应时，削弱这一条件下的主张 |
| 3. 特异性与恢复 | 使用独立原理或独立靶向的验证来检查非目标效应，并设计恢复 X 功能的比较；对照应匹配恢复操作本身。同步评估总体活性／损伤等替代解释 | 不同策略一致、且恢复能逆转 Y 的变化，可加强效应来自 X 的解释 | 只有单一策略有效，或 Y 变化完全伴随普遍损伤，需优先排查替代解释；恢复失败还可能是恢复未达成、时序不合适等，不能单独作终局否定 |
| 4. 指定路径的中间环节 | 只有要声称“通过 M”时才进入此环节：预先提出 M，检查 X 改变后 M 的变化及其时间关系，并用针对 M 的比较、阻断或恢复设计检验其是否改变 X 对 Y 的效应 | 支持一个限定系统内的路径模型；需要同时考虑 M 干预对 X 或 Y 的其他直接作用 | 单纯 X–M–Y 相关或富集不能证实中介因果。M 的干预有非目标效应、顺序不清、结果相互冲突时保留不确定；不声称已排除所有平行路径 |

**预设主要指标：** X 干预与匹配对照之间的 Y 效应，报告效应量及不确定区间。若主张仅在应激下存在，预设应激×X 干预的比较，避免用“一个组显著、另一个不显著”直接断言两组效应有差异。

**辅助指标：** X 干预达成程度、M 的响应、独立策略一致性、恢复程度，以及总体状态／损伤指标。辅助指标不能在主指标失败后临时变成成功标准。独立生物来源是推断范围的关键，孔级测量按层级处理。

**阈值与样本量：** 当前没有 Y 的量纲、变异或领域可接受差异，不能给假精确的数值。建议先以既有资料或独立先导估计确定最小有意义效应、测量变异、精度／功效目标和可接受损耗；据此安排独立生物重复。对多候选、多结局的选择及比较预设处理规则。若功效或精度不足，阴性结果记为“不确定”，不能断言无效。

**停止规则：** 关键测量不能可靠工作、独立性无法保证或干预达成失败时，先停止因果推断并排查设计；干预达成且主要效应精确落在预设无实质差异范围时，停止在该条件下扩写 X→Y。主要结果不确定时，保留不确定，不事后搜索有利子群。若之后探索子群，单独标为新假设，并用独立数据验证。

**范围与耗时：** 先选择一个系统、一个 Y、一个有理由的 X 假设。最早的设计检查可以在短期完成，但完整生物验证时间取决于模型建立、材料、独立生物来源和测量周期，目前不能承诺两周完成。如果只有公共观察性表达数据而没有可用干预证据，最小交付应是关联复核、替代解释分析和此验证计划，不能交付已证实的因果机制。

**至多两个退路：** 一是降为“稳健关联与候选机制”并公开局限；二是在预设系统得到可靠阴性结果时，报告该条件下的边界，而不是扩大到所有系统或事后换指标。实际数据、外部文献、新颖性及实验结果均尚未核实。

## 基于这一次输出的评价
