1. **建议优先做：** 用不确定性筛选的跨物种伪标签方法（c001）——场景具体、成本低、三周内有信号

3. **主要风险：** 跨物种子集可能泄漏（同源蛋白被分到训练与测试两侧），必须先查数据划分

当前聚焦：**新物种蛋白的功能标注稀缺，导致模型无法直接迁移**。

## 二、这个方向的真问题

### 现有工作在做什么

1. 在海量序列上做自监督预训练（序列重建、对比学习），再在下游分类任务上微调。
2. 用同源蛋白的功能迁移做注释，依赖序列相似度。
3. 用自训练生成伪标签扩充标注集。
4. 用不确定性估计挑选高置信样本，但主要在同分布内验证。
5. 用分布外检测判断输入是否可信。

### 它们共同没解决的

**伪标签的错误会自我强化。** 现有工作的隐含假设是"高置信伪标签基本正确"，但跨物种时模型本身就没见过目标分布，高置信恰恰可能来自过拟合训练分布。这个失败机制说清了，解决方向就清楚了：**筛伪标签的标准不能只看模型自信度，要看它是否偏离了训练分布**。

### 从需求侧看还缺什么

实际使用者（做新物种注释的实验室）没有 GPU 集群，只能拿一个小模型在自己数据上微调。现有方法动辄需要重新预训练，成本不接受。**轻量适配是一个被忽略的约束。**

### idea 1：不确定性筛选的跨物种伪标签（c001）

- **场景：** 目标物种标注少于 100 条，源物种标注充足
- **问题：** 朴素自训练在跨物种时，错误伪标签被反复固化，F1 不升反降
- **做法：** 用"预测不确定性 + 特征空间距离源分布的距离"双判据筛伪标签，只保留两个判据同时通过的样本；被拒样本做一致性正则而非丢弃
- **对比：** 与朴素自训练、置信度阈值法、纯微调三个基线比
- **证伪条件：** 若双判据筛出的样本与随机筛出的同等数量样本相比，macro-F1差异的预设置信区间不能排除无提升，则结果为未证明优于随机筛选；置信水平及实用提升阈值需在实验前设定
- **最小验证：** SwissProt 跨物种子集 / 基线：自训练 + 序列预训练模型 / 指标：macro-F1 / 建议的实用提升门槛：+3分（演示值；需按任务预先定标） / 耗时：3 天
- **示例检索状态：** 仅为演示文本；检索记录仍待填写，不能据此断言已确认新颖性

### idea 2：长尾事件预测（c002）

- **场景：** 故障/极端事件的时间序列，尾部类别占比 < 1%
- **问题：** 重加权后尾部仍学不到，因为尾部样本太少导致梯度噪声大于信号
- **做法：** 先学事件驱动因子（因果结构），再在因子空间里做尾部合成，而非在原始空间重采样
- **证伪条件：** 合成样本的分布与真实尾部差异显著（用双样本检验），或下游提升不随合成量单调增长
- **最小验证：** 公开故障数据集 / 基线：重加权 + 重采样 / 指标：尾部类 F1 / 建议的实用提升门槛：+5分（演示值；需按任务预先定标） / 耗时：1–2 周
- **风险：** 因果结构学习本身不稳定，可能整条链失效。**建议先做 c001，此题作为后备。**
