# 报告模板

## 本文目录

- 通用规则
- 模板 A：找 idea
- 模板 B：拆包装
- 模板 C：淬炼想法
- 模板 D：素材库周报

## 通用规则

- **结论先行**：开头 3 条以内，每条不超过 40 字
- **禁止空话**：任何删掉后信息量不变的句子都删掉
- 事实性主张须给出处或可核查数据；没有证据时标为"待验证"。建议和推断须与事实分开，不为凑引用而编造来源或数字。
- **长度控制**：可按用户用途压缩或展开，不为达到字数重复内容
- 报告是给"要动手的人"看的，不是给评审看的，所以**行动建议必须具体到下一步能做什么**

```markdown
# <研究方向> 选题分析

## 结论

1. 建议优先做：<一句话>
2. 关键依据：<一句话>
3. 主要风险：<一句话>

## 一、方向收敛

| 维度 | 你的选择 | 说明 |
|---|---|---|
| 对象 | | |
| 任务 | | |
| 约束 | | |
| 尺度 | | |

当前聚焦：**<场景一句话>**

## 二、这个方向的真问题

### 现有工作在做什么
（3–5 条，每条一句话，不展开）

### 它们共同没解决的
（这是全篇最重要的部分，2–3 条，每条要能说清失败机制）

### 从需求侧看还缺什么
（结合用户实际场景/行业实践，1–2 条）

## 三、候选 idea

| # | 一句话 | 新颖性 | 可行性 | 风险 | 建议 |
|---|---|---|---|---|---|
| 1 | | 完全相同/高度相近/部分重叠/本次未检出/未核实 | 高/中/低 | | 优先做/备选/放弃 |

### idea 1：<标题>

- **场景**：
- **问题**：现有方法在这里为什么失败
- **做法**：具体机制，不是"用 XX 模型"
- **对比**：和谁比，预期差在哪
- **证伪条件**：什么结果说明它错
- **最小验证**：数据 / 基线 / 指标 / 判据 / 耗时
- **检索状态**：记录实际检索日期、来源、查询词和最相近工作；没有实际检索时标为未核实。

（idea 2、3 同格式）

## 四、下一步（两周内可执行）

1. [ ] 具体动作
2. [ ] 具体动作
3. [ ] 具体动作

## 附录：检索记录

| 日期 | 关键词 | 来源/链接 | 时间范围 | 命中数或不可得 | 查看范围与最相关工作 |
|---|---|---|---|---|
```
