# 拆包装：把论文从叙事还原成事实

目标：读完一篇论文后，能用 30 个字说出它的本质，并判断值不值得跟、跟的话从哪切入。

## 为什么要剥

多数论文的结构是：**发现一个问题 → 说明它重要 → 指出前人不足 → 提出方法 → 证明更好**。其中"重要"和"不足"两部分最容易掺水，因为它们是修辞，不是事实。方法本身往往很简单——一个 loss 项、一个模块、一个数据构造方式。

摘要与引言用于理解作者的动机和主张，不能单凭篇幅推断贡献大小。

## 四层剥离法

### 第一层：故事层

只看 Abstract 和 Introduction 的前三段。回答两个问题：

- 它承诺解决什么"大问题"？（通常很大，比如"让模型具备推理能力"）
- 它用什么话术建立紧迫感？（"然而，现有方法仍面临……"）

**这一层的产出不需要记忆，只需要识别。** 记录下它的核心叙事是什么就行。

### 第二层：声明层

看贡献列表（Contributions / Our contributions）。通常有 3 条。逐条分类：

| 类型 | 特征 | 可信度 |
|---|---|---|
| 新问题 | "我们首次定义/研究 X 问题" | 需查证是否真首次 |
| 新方法 | "我们提出 X 模块/框架" | 需看方法部分核实 |
| 新数据/基准 | "我们构建了 X 数据集" | 较易核实，价值独立 |
| 新发现 | "我们发现 X 现象" | 需看证据是否偶然 |

要点：**贡献列表里出现"首次""首个"时，一定去核实**。跨领域、跨会议、不同命名下的同类工作经常被忽略，这是最常见的夸大方式。

### 第三层：实际层（关键）

只看 Method 部分：公式、架构图、算法伪代码。用下面这个问题过一遍：

> **把它的方法写成"已有做法 + 具体差异"；哪些结论有证据支持？**

操作步骤：

1. 找到它对比的最强 baseline，写下它的流程
2. 写下本文的流程
3. 逐行对齐，圈出差异部分
4. 记录：差异是理论、方法、数据、训练策略、评测设定或其他贡献；判断论文证据能否支持作者主张

不要用代码行数、组件占比或固定百分比衡量贡献。小的改动也可能解决重要问题；贡献需要结合问题价值、设计理由、对照证据、理论或数据贡献来判断。

同时警惕三种"伪增量"：

- **重组已有模块**：核对每个组件的来源，以及组合带来的新机制或新证据；命名本身不构成贡献
- **复杂度与收益**：同时核对效果差异、波动范围、计算与标注成本，不以单次小幅差值下结论
- **换了评测设置**：在更宽松的设定下比较，比如更少的 baseline、更弱的对手

### 第四层：证据层

看 Experiments。逐项检查：

| 检查项 | 红旗信号 |
|---|---|
| Baseline 选择 | 缺少与论文主张相称的强基线；未解释基线选择 |
| 消融实验 | 没有消融 → 无法证明新增模块有用；只删一个模块 → 未验证交互 |
| 指标选择 | 只报道有利指标；主指标不显著时改报副指标 |
| 显著性 | 无方差、无重复实验、单次结果 |
| 泛化 | 只在自家数据集上有效；换成通用数据集效果下降 |
| 负结果 | 重要限制或失败案例未报告；仅凭未提负结果不推断实验不存在 |
| 成本 | 只报效果不报时间/显存/标注成本 |

**证据层的结论只有三种**：充分、不足、无法判断（信息缺失）。不要模棱两可。

## 产出格式

固定输出这张表：

| 论文声称 | 实际做法 | 真实增量 | 证据强度 | 可攻击点 |
|---|---|---|---|---|
| 提出 X 模块解决 Y | 现有基线加一个注意力重加权，具体细节按论文核对 | 需结合问题价值和实证判断，不以改动大小代替价值 | 不足：缺与相关基线的直接对比 | 在高噪声数据下是否仍有效，未测 |

再加一句结论：

> **本质是：** 用 XX 换来了 YY，在 ZZ 设定下有效。

## 从拆解到自己的 idea

拆完不是结束。**表里"可攻击点"那一列，就是你的选题来源。**

对每个可攻击点问三句：

1. 这个攻击点如果成立，影响有多大？（影响小 → 放弃）
2. 我有没有条件做这个验证？（没数据/没算力 → 放弃或换角度）
3. 如果它真被推翻，我的替代方案是什么？（说不出 → 这只是抱怨，不是 idea）

三条都过得去，就把它转成一张 idea 卡片（模式 D），卡片格式里"短板"字段直接填这个攻击点。

## 常见误判

- **"我看不懂，所以很深"**：多数情况下是写得绕，不是想得深。看不懂就回去看架构图，图比文字诚实。
- **"引用量高所以重要"**：引用量反映传播，不反映正确性。经典论文也可能有未验证的假设。
- **"顶会所以可信"**：会议等级降低但不消除上述问题，尤其是在方法特别简单的论文上。
