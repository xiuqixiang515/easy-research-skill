# 能源（核算 / 系统评估 / 储能与转换）

> 加载条件：识别到学科为能源时加载；与 `../research-types.md` 对应段叠加。
> 检查清单，不是行业标准；不构成 LCA 或碳核算的合规认证。

## 1 最低证据清单（必填槽位）

| 槽位 | 必填 | 要问的问题 | 缺失时的后果 |
|---|---|---|---|
| 功能单位 | 是 | 每 kWh、每吨产品、每平方米、每服务单元？ | 分母不同则结论不可比 |
| 系统边界 | 是 | 使用阶段 / 全生命周期 / 含上游燃料与设备制造？ | 边界一变，减排数字可能反号 |
| 时间跨度与代表性 | 是 | 单日、月度、年度？季节性如何？ | 一天的外推常导致全年结论错误 |
| 初末状态 | 是 | 储能 SOC 初末一致吗？循环边界？ | 透支储能会被当成节能 |
| 辅助能耗 | 是 | 泵、风机、控制、冷却算了吗？ | 低负荷时辅助占比高，收益被高估 |
| 因子来源 | 是 | 电网因子/排放因子的地区、年份、口径 | 用全国均值掩盖区域差异 |
| 守恒与效率定义 | 是 | 效率的分母是什么？能量平衡闭合吗？ | 效率可被口径放大 |
| 敏感性 | 是 | 哪些假设主导结果？高低档差多少？ | 单点结论无法判断稳健性 |
| 基线可比 | 是 | 基线期与报告期的天气、产量、工况是否需要修正？修正方法是什么？ | 改造前后的差异可能来自环境而非改造 |

## 2 常见错误结论

| 错误结论 | 为什么错 | 追问 |
|---|---|---|
| "碳排下降 35%" | 未声明功能单位与边界，分母可能变了 | 每吨产品的碳排差多少？边界含上游吗？ |
| "两个工艺能耗差 12%，后者更环保" | 能耗低 ≠ 碳排低 | 用本地电网因子重算，方向还一致吗？ |
| "某系统一天节能 20%，年节电 XX 万度" | 单日外推忽略季节与负荷变化 | 有全年或至少四季数据吗？ |
| "加储能使系统更高效" | 若初末 SOC 不同，等于透支存量 | SOC0 与 SOC1 相等吗？ |
| "效率 82%" | 分母未定义，可能只算主机 | 辅助能耗计入分母了吗？ |

## 3 检索源

| 用途 | 入口 | 注意 |
|---|---|---|
| 文献与报告 | OSTI、NREL/OpenEI、IEA、ScienceDirect | 区分同行评审与机构报告 |
| 电网与排放因子 | 电网运营商统计、IPCC EFDB、区域因子库 | 必须写年份与地区 |
| 标准 | ISO 50001/14040 系列、IEC 相关标准 | 作为方法参考，不声称合规 |
| 数据仓库 | 开放能源数据平台、统计年鉴 | 注意统计口径变化 |

## 4 与四模式的接口

- **A 找 idea**：候选先定功能单位与边界，再谈技术路线；没有分项计量时，只能做区间估算并写明。
- **B 拆论文**：除通用七项外，先查分母与边界，再查时间代表性、初末状态、辅助能耗、因子来源。
- **C 淬炼想法**：最小验证=同边界复算 + 因子敏感性 + 区间；区间跨零则不给方向性结论。
- **D 素材库**：`--set-extra 学科=能源 --set-extra 研究类型=核算 --set-extra 功能单位=1t产品 --set-extra 边界=使用阶段 --set-extra 时间跨度=1年`

## 5 自查

1. 功能单位是什么？分母有没有变？
2. 边界包含哪些阶段？与对照是否同边界？
3. 时间跨度能代表全年吗？
4. 储能初末状态一致吗？
5. 关键因子取哪一年、哪个地区？换一档结论还成立吗？
