# 机械（仿真 / 试验 / 设计优化）

> 加载条件：识别到学科为机械时加载；与 `../research-types.md` 对应段叠加。
> 检查清单，不是行业标准；不能据此声称符合某规范。

## 1 最低证据清单（必填槽位）

| 槽位 | 必填 | 要问的问题 | 缺失时的后果 |
|---|---|---|---|
| 几何与材料 | 是 | 关键尺寸、材料牌号、热处理、本构模型；名义值还是实测值？ | 参数不确定时，误差无法归因 |
| 载荷与边界 | 是 | 载荷谱/加载速率、约束方式（理想固支 vs 夹具柔度） | 边界过刚会高估约束、低估位移 |
| 网格与收敛 | 是 | 网格无关性做了吗？残差与时间步？ | 单网格结果不可复现，可能"凑"实验 |
| 求解设置 | 是 | 单元类型、接触、非线性、求解器版本 | 他人无法复现 |
| 实测校核 | 是 | 试样数、测量手段、误差带；仿真与实测比的是哪个量 | "误差 4%" 可能是应力也可能是位移 |
| 工况覆盖 | 是 | 单工况还是多工况？外推范围？ | 单工况结论不能指导设计 |
| 失效模式 | 建议 | 强度、刚度、屈曲、疲劳、公差，哪个先到？ | 约束转移会被漏掉 |
| 率相关与惯性 | 视情况 | 结论要外推到冲击/高频工况吗？应变率、惯性、能量平衡交代了吗？ | 准静态结论被当成动态结论 |

## 2 常见错误结论

| 错误结论 | 为什么错 | 追问 |
|---|---|---|
| "仿真与实测误差 4%，模型可指导设计" | 单工况单网格，四处不确定性可能互相抵消 | 网格加密后误差变大还是变小？边界改柔性呢？ |
| "壁厚减 0.2 mm，应力仍合格，结构已优化" | 屈曲/刚度/公差可能先失效 | 一阶屈曲因子多少？位移超限吗？ |
| "材料用名义值即可" | 增材/焊接件分散性大 | 同批试样实测强度与名义值差多少？ |
| "3 根试样说明重复性好" | 3 根只能给粗略离散度 | 强度变异系数多少？够算区间吗？ |
| "仿真最优即实物最优" | 残余应力、缺陷、装配偏差未建模 | 有没有做一次破坏性验证？ |
| "准静态合格，冲击下也没问题" | 率相关本构、惯性与能量吸收未验证 | 应变率跨了几个量级？有没有落锤或 Hopkinson 数据？ |

## 3 检索源

| 用途 | 入口 | 注意 |
|---|---|---|
| 文献 | Engineering Village/Compendex、ASME Digital Collection、ScienceDirect | 工程类会议与期刊并重 |
| 标准与规范 | ISO、ASTM、GB/T（通过标准全文库） | 标准版本年份必须写 |
| 专利 | Espacenet、CNIPA | 结构改进类大量在专利 |
| 手册与数据 | 材料手册、NIST 数据 | 手册值不等于来料实测值 |

未查标准时写"未核对标准条款"，不得暗示合规。

## 4 与四模式的接口

- **A 找 idea**：候选必须带"工况范围"与"可获得的试样数"；资源不足时改为模型可信度研究，而不是最优设计。
- **B 拆论文**：除通用七项外，加查收敛、边界、材料来源、实测样本数、失效模式覆盖。
- **C 淬炼想法**：最小验证优先做网格收敛与边界敏感性（不改硬件），再做实测；判据按用途分档。
- **D 素材库**：`--set-extra 学科=机械 --set-extra 研究类型=仿真 --set-extra 单位=MPa/mm --set-extra 试样=3根 --set-extra 仪器=万能试验机`

## 5 自查

1. 我的误差是哪个量的误差？应力、位移还是刚度？
2. 网格无关性做了吗？加密后趋势如何？
3. 边界是理想固支还是考虑了夹具？
4. 材料是名义值还是同批实测？
5. 除了强度，屈曲、刚度、公差、疲劳查了吗？
