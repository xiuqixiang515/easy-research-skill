# 化学（合成 / 催化 / 分析测量）

> 加载条件：识别到学科为化学时加载；与 `../research-types.md` 对应段叠加。
> 检查清单，不是行业标准；不能据此声称合规。

## 1 最低证据清单（必填槽位）

| 槽位 | 必填 | 要问的问题 | 缺失时的后果 |
|---|---|---|---|
| 物质身份 | 是 | 凭什么说它是目标物？NMR/HRMS/XRD/元素分析哪几项？ | 后续所有活性/性能结论都建在未确认的物种上 |
| 纯度 | 是 | 纯度多少、怎么测（HPLC 面积比 / qNMR / 元素分析）？ | 活性可能来自杂质 |
| 计量定义 | 是 | 转化率、选择性、产率分别是"对什么"算的？分母是谁？ | 三个数常被混用，结论不可比 |
| 独立批次 | 是 | 几批？独立配制还是同批分装？ | 单批次无法评估重现性 |
| 空白与回收 | 是 | 空白、加标回收率、LOD/LOQ 各是多少？ | 低浓度结论不可信 |
| 条件 | 是 | 温度、溶剂、浓度、气氛、搅拌、含水量 | 无法复现，也无法归因 |
| 正交表征 | 建议 | 机理或结构主张是否有第二种独立手段？ | 单一谱图推结构风险高 |
| 放大与工艺 | 视情况 | 克级到公斤级，传热传质是否变化 | 放大后结论可能失效 |

## 2 常见错误结论

| 错误结论 | 为什么错 | 追问 |
|---|---|---|
| "降解率 98%" | 未扣空白与回收，可能含吸附/挥发/取样损失 | 回收率多少？空白扣了吗？ |
| "UV-Vis 峰位红移 5 nm，说明结构改变" | 溶剂化、pH、离子强度、聚集都能红移 | 变浓度、加盐、换溶剂后位移还在吗？ |
| "产率 82%，所以这条路线更好" | 未给选择性与纯度；后处理成本未计 | 选择性多少？杂质谱如何？ |
| "单批次重复三次，重现性良好" | 同批分装不是独立批次 | 独立配制了几批？批间偏差多少？ |
| "催化剂可回收五次，活性不变" | 未做浸出与结构表征，可能是均相贡献 | 滤液是否仍有活性？金属浸出量多少？ |

## 3 检索源

| 用途 | 入口 | 注意 |
|---|---|---|
| 化合物是否已知 | SciFinder/CAS、Reaxys、PubChem | 结构检索优先于关键词 |
| 晶体结构 | CSD（CCDC）、ICSD | 同名不同晶型常见 |
| 文献 | Web of Science、Scopus、Google Scholar | 学科限定与时间范围要记录 |
| 专利 | Espacenet、CNIPA | 工艺类工作大量在专利里，不能只看论文 |

无订阅权限时明确写"未查 CAS/CSD"，不得据记忆断言"未见报道"。

## 4 与四模式的接口

- **A 找 idea**：候选必须写清"用什么表征确认产物"与"几批"，否则标为不完整；"探索机理"是合法选题，但必须给出"什么观测能区分两个机制"。
- **B 拆论文**：除通用七项外，加查身份、纯度、计量定义、独立批次四条。
- **C 淬炼想法**：最小验证先做回收率与空白，再做条件对比；判据按"超过批间偏差"设定。
- **D 素材库**：`--set-extra 学科=化学 --set-extra 研究类型=实验 --set-extra 单位=mol/L --set-extra 批次=3 --set-extra 仪器=NMR`

## 5 自查

1. 我的产物身份与纯度有独立证据吗？
2. 转化率/选择性/产率三个数，分母各是什么？
3. 几个独立批次？批间偏差多大？
4. 低浓度结论扣空白、做回收了吗？
5. 结构或机理主张，有没有第二种独立手段？
