# 生物（实验 / 观察 / 组学）

> 加载条件：识别到学科为生物时加载；与 `../research-types.md` 对应段叠加。
> 检查清单，不是行业标准；不能据此声称合规。

## 1 最低证据清单（必填槽位）

| 槽位 | 必填 | 要问的问题 | 缺失时的后果 |
|---|---|---|---|
| 实验单位 | 是 | n 指的是个体、孔、皿、窝还是田块？ | 单位错位会让统计检验整体失效 |
| 重复类型 | 是 | 技术重复与生物学重复各几次？ | 技术重复当独立样本会低估标准误 |
| 批次 | 是 | 几个独立批次？处理与对照是否同批？ | 批次效应会被误读成处理效应 |
| 随机化与盲法 | 是 | 分组是否随机？测量者是否知道分组？ | 选择偏倚与测量偏倚 |
| 统计方案 | 是 | 主比较是什么？多重比较怎么校正？ | 事后挑比较会虚高显著 |
| 资源身份 | 建议 | 细胞系来源与认证、抗体 RRID、菌株/品系编号 | 无法复现，也无法排除混淆 |
| 样本量依据 | 是 | 依据效应量与变异做的功效估计，还是"惯例 n=3" | 结论可能只是功效不足 |

## 2 常见错误结论

| 错误结论 | 为什么错 | 追问 |
|---|---|---|
| "n=3，三次独立实验" | 未说明是生物学还是技术重复 | 三个独立样本分别来自哪里？同期还是分批？ |
| "处理组高 15%，说明处理有效" | 未与株间/批间变异比较 | 对照组自身的变异系数多少？ |
| "差异基因很多，揭示了调控网络" | 未校正多重比较；网络是推断不是观测 | 校正后剩多少？换参考基因结论稳定吗？ |
| "相关分析表明 A 调控 B" | 相关不等于因果 | 有时间顺序证据吗？干预后表型变吗？ |
| "细胞系是 XX" | 未做 STR 认证或来源不明 | 有认证报告吗？支原体检测呢？ |

## 3 检索源

| 用途 | 入口 | 注意 |
|---|---|---|
| 文献 | PubMed、Web of Science、bioRxiv | 用 MeSH 词提高召回，记录检索日期 |
| 数据集 | GEO、ArrayExpress、SRA/ENA | 复用数据要核对批次与处理 |
| 质粒/细胞 | Addgene、Cellosaurus、RRID 门户 | 资源身份可追溯 |
| 通路与注释 | GO、KEGG、Reactome | 注释版本要写 |

不得把"未检索到"写成"没有相关研究"。

## 4 与四模式的接口

- **A 找 idea**：观察性/描述性选题是合法方向；候选要写清"实验单位"与"能测到的效应量下限"，不要强行包装成机制研究。
- **B 拆论文**：除通用七项外，加查实验单位、重复类型、批次平衡、多重比较四条。
- **C 淬炼想法**：先确认"差异是否超过变异"，再谈机制；组学只作假设生成，因果需干预实验。
- **D 素材库**：`--set-extra 学科=生物 --set-extra 研究类型=描述性 --set-extra 重复=3生物学+2技术 --set-extra 批次=2`

## 5 自查

1. 我的 n 到底是什么单位？技术重复有没有被算进去？
2. 处理与对照是同批吗？批间偏差测过吗？
3. 多重比较校正了吗？主比较是事前定的吗？
4. 我说"调控/导致"时，有没有时间顺序与干预证据？
5. 细胞系、抗体、菌株能追溯到编号吗？
