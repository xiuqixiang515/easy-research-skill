# 医学（诊断 / 预测 / 干预 / 流行病学）

> 加载条件：识别到学科为医学时加载；与 `../research-types.md` 对应段叠加。
> 检查清单，不是行业标准；不构成合规认证，也不替代伦理与统计审查。

## 0 先分设计（这一步错了，后面全错）

| 你要回答的问题 | 设计类型 | 关键锚点 |
|---|---|---|
| 这个指标能不能区分有病/没病 | 诊断准确性 | 目标人群、参考标准、盲法 |
| 未来会不会发生某事件 | 预后/预测模型 | t0、预测时点、验证范围 |
| A 是否导致 B | 因果（队列/病例对照/RCT） | 混杂、时间顺序、偏倚 |
| 干预是否改善结局 | 干预研究 | 随机化、对照、终点、样本量 |
| 某现象有多常见 | 描述性/横断面 | 抽样框、应答率 |

先让用户确认要回答哪一类；他想答"能不能改善结局"却拿回顾性数据，要直接指出设计不匹配。

## 1 最低证据清单（必填槽位）

| 槽位 | 必填 | 要问的问题 |
|---|---|---|
| t0（时间零点） | 是 | 从哪一刻开始算预测/随访？变量都在 t0 前可得吗？ |
| 目标人群与入排 | 是 | 连续入组还是便利抽样？排除了哪些人？ |
| 参考标准 | 是 | 金标准是什么？判读是否盲法？ |
| 验证范围 | 是 | 表观 / 内部（拆分或交叉）/ 时间外 / 外部，哪一级？ |
| 性能指标 | 是 | 敏感性、特异性、AUC 之外，报校准与区间了吗？ |
| 事件数 | 是 | 结局事件多少例？相对候选变量数够吗？ |
| 时间可比性 | 是 | 随访时长、人时、失访比例；训练期与验证期的诊疗规范、测量方式是否一致？ |
| 缺失与失访 | 是 | 缺失比例、处理方式、失访是否与结局相关 |
| 治理 | 是 | 伦理批件、去标识化、数据使用边界 |

## 2 常见错误结论

| 错误结论 | 为什么错 | 追问 |
|---|---|---|
| "敏感性 92%、特异性 88%，可临床使用" | 确诊+健康对照的谱偏倚会同时抬高两者 | 连续入组的可疑人群里还剩多少？ |
| "AUC 0.86，可用于筛查" | 阈值在同一批数据上选出，性能乐观；筛查人群阳性预测值低 | 阈值在独立数据上验证过吗？ |
| "内部验证 AUC 0.90" | 同批训练+验证是表观性能 | 拆分了吗？固定超参了吗？ |
| "入院后指标预测入院时风险" | 时间泄漏 | 变量在 t0 时点可得吗？ |
| "回顾性显示用药者预后更好" | 适应证混淆（健康者偏倚） | 有没有做倾向评分或工具变量？ |
| "HR 0.6，风险降低 40%" | 只有相对效应，没有随访人时，换算不出绝对风险 | 随访多久？失访多少？绝对风险差是多少？ |

## 3 检索源

| 用途 | 入口 | 注意 |
|---|---|---|
| 文献 | PubMed、Embase、Cochrane Library | 记录检索式与日期 |
| 在研/已完成试验 | ClinicalTrials.gov、ChiCTR、WHO ICTRP | 查"是否已有人做过"必查 |
| 系统综述注册 | PROSPERO | 避免重复综述 |
| 报告规范 | TRIPOD+AI、STARD、STROBE、PRISMA | 作为自查清单使用，**不声称合规** |
| 指南 | 各学会指南 | 注意版本年份与适用人群 |

## 4 与四模式的接口

- **A 找 idea**：先定设计类型，再给候选；资源不足时优先做诊断准确性或一致性研究，而不是硬做干预。
- **B 拆论文**：除了通用七项，先查设计是否回答了它声称的问题，再查 t0、谱偏倚、盲法、区间、校准。
- **C 淬炼想法**：最小验证要写"t0 与入组方式"；判据用区间不跨阈值；伦理等待不可压缩。
- **D 素材库**：`--set-extra 学科=医学 --set-extra 研究类型=诊断准确性 --set-extra t0=首次就诊 --set-extra 验证=时间外`

## 5 自查

1. 我回答的是诊断、预测、因果还是干预？
2. t0 是什么？所有变量都在 t0 前可得吗？
3. 入组是连续的吗？健康对照占比多少？
4. 参考标准盲法了吗？性能有区间和校准吗？
5. 我有没有把"预测性能"说成"临床获益"？
