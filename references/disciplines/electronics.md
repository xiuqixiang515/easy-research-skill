# 电子信息（电路 / 通信 / 信号与测量）

> 加载条件：识别到学科为电子信息时加载；与 `../research-types.md` 对应段叠加。
> 检查清单，不是行业标准；不构成测试认证。

## 1 最低证据清单（必填槽位）

| 槽位 | 必填 | 要问的问题 | 缺失时的后果 |
|---|---|---|---|
| 被测量的定义 | 是 | ENOB、SNR、BER、线性度分别怎么算？参考带宽是多少？ | 指标口径不同则不可比 |
| 激励条件 | 是 | 频率、幅度、采样率、时钟来源、输入阻抗 | 单点结果无法代表带宽内表现 |
| 带宽/功率公平性 | 是 | 对比方案是否同带宽、同发射功率、同采样率 | 靠多占资源换来的增益不成立 |
| 噪声与信道 | 是 | 噪声模型、信道模型、SNR 工作点 | 单 SNR 点结论不可外推 |
| 同步与前端 | 是 | 定时/载波/帧同步、ADC 前端、滤波器、去耦 | 同步失败会被误读为算法问题 |
| 测量链本底 | 是 | 仪器与参考源的不确定度、本底 SFDR/相位噪声 | 可能测的是仪器而不是被测件 |
| 重复维度 | 是 | 板间、频点、温度、上电次数各几次 | 单板单点无法区分个体差异 |
| 实测 vs 仿真 | 是 | 仿真是否含寄生、器件容差、时钟抖动 | 仿真结论不能当实测 |

## 2 常见错误结论

| 错误结论 | 为什么错 | 追问 |
|---|---|---|
| "ENOB 提升 0.7 bit，前端具普适优势" | 单板单频点室温，未报参考源不确定度 | 换 3 块板、3 个频点后还在吗？ |
| "BER 从 1e-3 降到 1e-4，方案更优" | 可能用了更大带宽或功率 | 同带宽同功率重测了吗？ |
| "仿真 SNR 提升 3 dB，可投论文" | 未含寄生与抖动 | 实测提升多少？带宽功耗代价呢？ |
| "测得 10 bit，接近理论值" | 未扣测量链本底 | 本底 ENOB 是多少？ |
| "室温测一次即可" | 温漂与上电离散未采样 | 5 次上电的极差多少？ |

## 3 检索源

| 用途 | 入口 | 注意 |
|---|---|---|
| 文献 | IEEE Xplore、IET、arXiv（eess） | 电路类重视测试条件表 |
| 标准 | ITU、3GPP、IEEE 802 系列 | 引用条款要写版本 |
| 器件与参考设计 | 厂商数据手册与应用笔记 | 属厂商文档，不等同独立验证 |
| 专利 | Espacenet、CNIPA | 电路结构改进常在专利 |

未核对标准条款时写"未查标准原文"，不要写"符合某标准"。

## 4 与四模式的接口

- **A 找 idea**：候选要写清"测什么、在什么条件下测、本底多少"；资源不足时先做测量链本底研究。
- **B 拆论文**：除通用七项外，查激励条件、公平性、本底、重复维度、仿真是否含非理想因素。
- **C 淬炼想法**：最小验证先测本底，再换板/换频点；判据按不确定度定最小可报告增益。
- **D 素材库**：`--set-extra 学科=电子信息 --set-extra 研究类型=实验 --set-extra 单位=bit;dBFS --set-extra 重复=5次上电 --set-extra 仪器=示波器1GHz`

## 5 自查

1. 我测的是被测件还是测量系统？本底多少？
2. 对比方案同带宽、同功率、同采样率吗？
3. 单板/单频点/室温，三个维度各采样几次？
4. 仿真里有没有寄生、容差、抖动？
5. 我引用的指标定义与参考带宽写清了吗？
