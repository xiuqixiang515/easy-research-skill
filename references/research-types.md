# 研究类型检查表

> 加载条件：识别出研究类型后加载对应一节；与学科文件叠加（学科决定"要哪些槽位"，类型决定"用什么证据判断"）。
> 一个任务可以跨类型（如"仿真 + 实验"），此时两节都读，并写清两侧证据在哪里相接。

## 0 先判断类型

| 如果用户的目标是…… | 类型 | 核心问题 |
|---|---|---|
| 预测未来状态或结局 | 预测 | 时点、人群、验证范围 |
| 判断 A 是否导致 B | 因果 | 混杂、时间顺序、反事实 |
| 在受控条件下比较处理 | 实验 | 单位、对照、重复、盲法 |
| 用模型替代或解释真实系统 | 仿真 | 收敛、边界、校核 |
| 推导或证明性质 | 理论 | 假设、证明、可检验推论 |
| 描述现象与分布 | 描述性 | 抽样、代表性、精度 |
| 复现他人结果 | 复现 | 环境、数据、差异归因 |
| 证明方案在工程上可行 | 工程验证 | 指标、工况覆盖、失效模式 |
| 算清能耗/碳排/资源账 | 核算 | 功能单位、边界、因子来源 |
| 判断指标能否区分有病/没病 | 诊断 | 人群、参考标准、阈值、验证范围 |

判断不清时先问一句："你希望读者看完相信什么？"——这句话通常直接指向类型。

## 1 预测

- 必需：时间零点 t0、目标人群、候选变量在 t0 可得、验证范围（表观/内部/时间外/外部）、事件数。
- 判据：区分度 + 校准 + 区间；外部验证优先于交叉验证。
- 时间可比性：训练期与验证期的诊疗规范、测量方式、编码口径是否一致。
- 越界：把预测性能说成临床/经济获益；用未来信息预测过去。
- 最小验证：留出时间外批次，固定模型后只报一次。

## 2 因果

- 必需：暴露与结局的时间顺序、混杂清单、对照来源（随机/自然实验/设计）、效应度量。
- 判据：能否排除主要替代解释；敏感性分析（E-value 之类需说明依据）。
- 时间可比性：随访时长、人时、失访比例；暴露与结局的时间窗是否合理。
- 越界：用相关数据说"导致"；用中介分析代替干预证据。
- 最小验证：负对照结局、剂量反应、或准实验设计。

## 3 实验

- 必需：实验单位、对照类型（空白/阳性/历史）、重复（独立批次）、随机化与盲法、主指标预注册。
- 判据：效应量 + 不确定度；"超过批间变异"比固定阈值更可靠。
- 越界：技术重复当独立样本；事后挑主指标。
- 最小验证：先做阴性对照跑通流程，再上处理组。

## 4 仿真

- 必需：几何/参数来源、边界条件、网格或时间步收敛、求解设置、校核数据。
- 判据：收敛 + 敏感性 + 与实测的一致性与误差带。
- 越界：单工况单网格结论外推到设计；把"与实测接近"当"模型正确"。
- 最小验证：网格三档 + 边界两档，看结论是否稳定。

## 5 理论

- 必需：显式假设、推导步骤、边界条件、可检验推论。
- 判据：推导自洽 + 推论可被观测检验 + 极限情形退化正确。
- 越界：用数值实验代替证明；假设未声明就下结论。
- 最小验证：找一个小规模可解情形或已知极限做核对。

## 6 描述性

- 必需：抽样框、样本量与代表性、测量精度、缺失情况。
- 判据：分布与不确定度；不强行给因果或机制。
- 越界：把描述写成"揭示机制"；用便利样本代表总体。
- 最小验证：换一个时间窗或子样本，看主要描述是否稳定。

## 7 复现

- 必需：原始材料版本、环境与依赖、数据划分、差异归因方法。
- 判据：能否复现主表；差异是否可解释。
- 越界：复现失败就说"原研究错误"；未记录环境差异。
- 最小验证：先复现一个最小结果（单表/单图），再扩。

## 8 工程验证

- 必需：验收指标、工况覆盖、失效模式、测试台架与不确定度。
- 判据：在最不利工况下仍满足指标；给出裕度。
- 越界：用最优工况代表全工况；忽略长期可靠性。
- 最小验证：挑最不利工况做一次，比全工况覆盖便宜。

## 9 核算（能耗 / 碳排 / LCA）

- 必需：功能单位、系统边界、时间跨度与代表性、因子来源（地区/年份）、初末状态（储能）、辅助能耗。
- 判据：同边界可比 + 敏感性区间；区间跨零则不给方向性结论。
- 基线可比：基线期与报告期的天气、产量、工况是否做过修正；未修正时只能给区间。
- 越界：用总量代替单位产品量；用单日/单月外推全年；把能耗下降说成碳排下降。
- 最小验证：同边界复算 + 关键因子两档敏感性。

## 10 诊断（准确性 / 一致性）

- 必需：目标人群与入组方式、t0、参考标准与盲法、阈值来源、验证范围、区间与校准。
- 判据：连续入组下的敏感性/特异性 + 区间；校准与区分度并列报告。
- 验证时点：参考标准与指标的测量时间差；时间差过大时结论只能算关联。
- 越界：确诊+健康对照的谱偏倚；在同一批数据选阈值再报性能；把诊断性能说成临床获益。
- 最小验证：小样本连续入组 + 盲法判读，先确认入组流程可行，再扩样本。

## 11 跨类型时的写法

- 先写"两侧证据在哪里相接"：例如"仿真给出机理，实验给出外部有效性"。
- 不允许用一侧的证据替代另一侧：仿真不能证明可制造，实验不能证明机理。
- 报告的结论段必须写明：哪些结论依赖哪一侧，另一侧缺失时结论降级为什么。
